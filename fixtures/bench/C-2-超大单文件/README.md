**构造说明**：按方案 §4.8 的"超大文件"档生成，行长度含正常与极端两类（覆盖方案 §5.1 的超长行边界）。

- **对应指标**：方案 §9.1 的"大文件吞吐"与"内存占用恒定"两项；
- **用途**：F01 流式分割、§4.3 的原子落盘与取消语义验证；
- **生成方式**：**已就绪**（`gen_c2.py`；默认 2 GiB＋64 MiB，`--size-mib` 可调；产物落 `out/`，**体积大不入库**，CI 按需生成或预置本地产物；小体积自测用 `--size-mib 8`）；
- **变量固定**：生成前须记录磁盘剩余空间与空闲内存，作为结果可比性的前提。
