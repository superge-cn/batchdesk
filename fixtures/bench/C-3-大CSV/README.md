# C-3 大 CSV（含引号换行）

**构造说明**：生成记录跨行的 CSV（字段内含转义引号与真实换行），数据量按需放大。

- **对应指标**：方案 §5.3 的分片正确性 + §9.1 的吞吐；
- **用途**：F05 的"禁止行中间切断"与每片保留表头的正确性验证（触发语料 T01/T02 的同类场景）；
- **生成方式**：已建 `gen_c3.py`（幂等自校验；`build_field`/`build_rows`/`build_csv_bytes` 为"引号换行 CSV"唯一构造器，**corpus/T02 语料脚本落地时 import 本模块复用，不重复实现**）；
- **变量固定**：列数、引号占比、跨行记录占比三项须在脚本内固定并写入生成日志。
