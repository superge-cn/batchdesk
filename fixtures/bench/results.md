## 2. 判定口径

- 是否达标只能取方案 §9.1 的对应行：目录清单＝10 万文件 ≤30 秒（SSD，界面始终可响应）；大文件吞吐分档＝NVMe／机械盘两组数值，本机是 **SATA SSD**（Samsung 870 EVO，见 C-4/记录1），落在两档之间，故吞吐结论只作下限参考、不作达标判定。
- R-01…R-03 的耗时是 **CLI 单进程**口径；§9.1 同一行还含"界面始终可响应"，R-06 还含"常态 ≤300 MB／可配预算 512 MB"——两者属桌面壳（渲染线程与内存预算），本轮**没有**测，记在 §3，不得由 CLI 数值代替。
- RSS 口径：`/proc/<pid>/status` 的 VmRSS 是瞬时值（50 ms 采样），非 high-water 标记。早期用 `resource.RUSAGE_CHILDREN.ru_maxrss`（high-water）对 C-1 另测得 ≤11.2 MiB；两个口径都远低于 §9.1 的 300 MB 档，结论不变。
- fsync：`crates/` 与 `src-tauri/` 的 Rust 源码内均无 `sync_all`／`sync_data` 调用（当次 `grep -rn` 复核，命中 0 行），故写侧吞吐含页缓存收益；基线（方案 v1.19）未规定断电刷盘语义，本表不据此立要求，只标注口径限制。
- **就地改写类（R-09…R-28）的 apply 读数按"源字节/秒"计，但一次 apply 的磁盘 IO 约为源体积的 4 倍**：整源备份进隔离目录（读＋写）→ 流式重写（读＋写）→ 原子改名。所以 C01 的 86.9 MiB/s 对应的实际 IO 速率约 350 MiB/s，不可与 F01 的 386.8 MiB/s（只写不备份）直接对撞比较。
- **写侧粒度曾是本组分档的主因，不是介质**：C01 按 64 KiB 块写出得 86.9 MiB/s，而 C02／C03 的改写器每行（每匹配）向裸 `File` 调一次 `write_all`（`crates/platform/src/fs.rs` 交出的是未加缓冲的 `File`）只有 3.9–5.6 MiB/s。该通道已按 [ADR-0078](../../docs/adr/0078-改写通道的写缓冲合块.md) 加 `BufWriter` 合块，复测见 R-19（C01 持平＝反向对照）、R-20（C02 整档 27 倍）、R-21～R-23（C03 三臂整档首测）与 R-25～R-28（R-13～R-16 四条子档的同体积后继）。**引用 R-13～R-18 这些读数必须带「合块前」这个限定**，它们不再是当前实现的吞吐。
- **§9.1 第③子句与 §4.8 的"内存占用恒定"按段判定**：计划段与改写段分别记。修复前 C03 计划段实测违背（R-17：VmRSS ≈体积 1.01 倍、cell 路 9.4 倍，2 GiB 三臂在 1 GiB 保险丝处被终止）；按 [ADR-0079](../../docs/adr/0079-C03计划段事实采集流式化.md) 把计划段改成逐块采集后，C03 plain 整档计划段峰值 4.0–4.5 MiB（R-21），regex／cell 见 R-22／R-23，三条臂与 C01（R-11 的 4.37 MiB）／C02（R-12 的 3.9 MiB）同量级。不得用改写段的读数去覆盖计划段的读数，反之亦然；**界定不出的正则两段都仍是 O(文件)**（ADR-0064 的同一闸门），不在"已流式"之列。
- **子档（C-2 集的前缀切片）不是 C-2 档**：R-13～R-16 与 R-25～R-28 的体积栏写明的是切片字节数，判定栏一律"不作达标"；整档读数是 R-09～R-12、R-17、R-18、R-19～R-24 这几条。ADR-0079 之后 C03 三臂都能出整档数值，R-13～R-16 保留为**修复前的子档对照**（各自的后继是 R-25／R-26／R-27／R-28），不要拿它们与 R-21～R-23 直接比速率（分母体积不同），也不要拿子档与整档比冷热——同一体积才能读出实现的差别。
- **多字节变体（R-29）不是 C-2 档，也不是任何达标依据**：T v1.12 附录 C 的 C-2 构造说明只有行长度这一维、没有编码维，
  所以现生成的 GB18030 多字节数据集不属于基线规定的档；本表用它只为回答「代价量级」。它的比值必须与**同窗口**的
  ASCII 对照（R-30）一起引，单引其一不成结论；把它升成正式档要人裁决（[OQ-42](../../docs/OPEN-QUESTIONS.md)）。
- **受扰动读数不入中位数**：手册 §2.5 要求关闭无关后台任务；本轮出现过并发会话把 loadavg 抬到 16.2–27.9 的窗口（见 §4 轮次 3），该组读数单独列出、只作为扰动证据，不参与任何结论。
- 未达标按 T §4.2 由产品所有者签发延期豁免（模板 F），豁免不进毕业验收（T §4.4）。
