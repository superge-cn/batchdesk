# C-6 重复文件集

**构造说明**：构造三类文件——① 同大小不同内容；② 同内容不同文件名；③ 硬链接（同一文件多个入口）。

- **对应指标**：方案 §5.10 的三段式哈希（大小分组 → 快速哈希 → 全量哈希）；
- **用途**：C09 的正确性（尤其第③类：硬链接**不得**被判为重复，见方案 §5.10 的边界与异常）；
- **生成方式**：**已就绪**（`gen_c6.py`；① 20 对 1 MiB、② 2 MiB 复制 10 份、③ 1 MiB 源 + 3 个硬链接；产物落 `out/` 不入库）；第③类在不支持硬链接的文件系统上会记录 `hardlink_unsupported` 并跳过该类的 inode 断言；
- **变量固定**：三类文件的数量与体积分布须固定并写入生成日志。

## C09 只读与计划预览断言

**已就绪**：`assert_c09.py`（Unix 主机；本地手动执行，CI 不生成 C-6）。

```bash
# 数据集不存在时一并生成
python fixtures/bench/C-6-重复文件集/assert_c09.py --generate
# 已生成时
python fixtures/bench/C-6-重复文件集/assert_c09.py
```

断言内容：

1. **full（无快速窗口）**：大小 → 全量两阶段；54 份数据集文件全部全量哈希，只有 `same_content/` 的 10 份成组，`same_size/` 无假阳性；
2. **full（三阶段）**：显式传 `--quick-window-bytes 4096`；54 份快速哈希后仅 14 份进入全量（10 份同内容 + 4 个硬链接入口），40 份被快速阶段淘汰；
3. **fast**：只算快速哈希（`full_hashed=0`），输出的组一律为 `candidate`，不得直接清理；
4. **硬链接**（支持硬链接的文件系统）：`hardlink_skipped` 恰为 3 个入口，且同内容组不含硬链接；不支持时跳过该断言并在 `gen.log` 记录；
5. **计划预览**：`--plan --keep shortest-path --plan-id <测试 ULID>` 只生成 `PlanDocument`：9 条 `delete`、保留 `copy_00.dat`、1 条 `hardlink-skipped` safe 告警；不执行 apply；
6. **计划默认值**：`--plan` 省略 `--keep` 时默认 `earliest`（OQ-29 已确认）；fast 模式生成清理计划仍以 E1002 拒绝；
7. **只读性**：所有运行（检测＋计划预览＋拒绝路径）前后 `out/` 的文件清单、大小、mtime 不变；
8. **参数门禁**：`--mode fast` 缺少显式窗口时拒绝运行。

说明：

- 窗口 `4096` 是**测试用显式参数**，不是产品默认值（OQ-28 仍待确认）；保留策略默认 `earliest`（OQ-29 已确认），断言中的 `shortest-path` 仅用于验证显式覆盖。
- `out/gen.log` 是生成日志，不是数据集；扫描时它会作为“唯一大小”文件被大小阶段淘汰，断言单独计数（数据集 54 个文件 + 日志 1 个）。
- 计划预览是只读的；C-6 断言不会写入任何文件。apply/undo、S02 保护目录与 cleanup 保留期的自动化覆盖在 `crates/cli/tests/apply_flow.rs`（真实文件系统临时目录，不影响 C-6 `out/`）。
