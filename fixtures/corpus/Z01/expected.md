# Z01 预期摘要

| 项 | 内容 |
|---|---|
| 类别 | 压缩 |
| 样本特征 | ZIP 内文件名为 GBK 编码、通用标志位**不含** bit 11（UTF-8 标志） |
| 预期行为 | 回退 GBK 解码并提示（方案 §5.11） |
| 判定权威 | T v1.12 §3.2 的 **Z01** 行（涉及功能与套件归属以该行为准） |
| 样本属性 | 需冻结哈希：`sha256 113faa19fc87c291839a9dad22574af7cc11e24c6c3ea1dbbe405378c6634abb`（199 字节） |

生成：`python fixtures/corpus/Z01/gen_z01.py` → `out/gbk_name.zip`（幂等）
实现要点：Python `zipfile` 总为非 ASCII 名写 UTF-8 标志，**无法**用它造出本样本；脚本按 ZIP 结构手写（存储、不压缩）
自校验：标志位无 bit 11；文件名可 GBK 解码且**不可** UTF-8 解码；结构可被标准库打开且内容一致
