# K01 预期摘要

**编码类｜特征**：GBK 中文 CSV，无 BOM。
**预期行为**：编码检测判定为 GB18030 并正确转码；转码后中文表头与数据行可读，且不引入替换字符。
**涉及功能**：C01、F05、F06（编码套件）。

---

**判定权威**：详细判定点见 **T v1.12 §3.2 的 K01 行**（"判定 GB18030 并正确转码（5.2）"）与基线《办公辅助工具产品方案》§5.2 的检测流水线（BOM 优先 → UTF-8 严格校验 → 统计判定 → 平台先验加权）。本文件只作三行摘要，**不复制判定文本**。

**样本属性（供回归断言使用）**

| 项 | 值 |
|---|---|
| 编码 | GBK（GB18030 子集） |
| BOM | 无 |
| 行尾 | CRLF |
| 数据行数 | 8 |
| 区分力约束 | 生成物必须**无法**作为 UTF-8 解码（由 `gen_k01.py` 自校验） |

**回归断言建议**

1. 检测结果落在 GB18030 类别，**不得**判为 UTF-8；
2. 转码为 UTF-8 后中文无替换字符（U+FFFD 计数为 0）；
3. 转码后行数与列数与源文件一致（8 行数据 + 1 行表头，4 列）。

> 若上述任一断言在实现中不成立，按 T v1.12 §5.2 判定为**缺陷**（与已确认决策不符）或**需求变更**（基线未定义），不得自行改预期。
