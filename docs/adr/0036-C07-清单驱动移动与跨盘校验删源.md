# 0036. C07 清单驱动移动/复制：路径安全与跨盘"复制→校验→删源"

- **状态**：已采纳（2026-11-01，开发代理按方案 §5.8 既定条款落工程语义）
- **日期**：2026-11-01
- **决策者**：开发代理（方案 §5.8 条款已定，本 ADR 只落实现口径与能力边界）
- **关联**：方案 §5.8（C07 详设）、§7.8（回滚语义）；设计 01 §5（`move`/`copy` 动作复用）；设计 04（FsAdapter 能力）；硬性不变量 1/2/4/7

---

## 1. 问题背景

方案 §5.8 定了 C07 的四条硬要求：路径安全解析（禁止 `..` 逃逸）、跨盘移动"复制→校验大小与哈希→删除源、校验不通过绝不删源"、目标目录按配置自动创建、缺失项跳过/报错可配。既有 `move_path` 的跨盘兜底是"复制＋删源"但**无校验**，且 FsAdapter 没有同卷判定与单文件删除能力——C07 之前必须补齐。

## 2. 候选与结论

| 议题 | 候选 | 结论 |
|---|---|---|
| 跨盘校验位置 | a) FsAdapter.move_path 内部；b) kernel 执行器（Move 臂） | **b**：校验需要"失败后按失败条目报告"的语义，属于执行编排而非适配器机制 |
| 同卷判定 | a) kernel 自行 stat dev；b) FsAdapter `same_volume` 能力 | **b**：平台差异（st_dev / 卷序列号）收口适配层；缺省 `false`＝保守按跨盘处理 |
| 删源能力 | a) `remove_to_quarantine`（挪进隔离）；b) FsAdapter `remove_file` | **b**：源数据已完整存在于目标（哈希校验通过），删源是**移动语义的后半步**而非内容删除；挪进隔离反而让用户在隔离目录里看到"幽灵副本" |
| 目标子目录创建 | a) 计划期展开为 `create-dir` 条目（F11 式）；b) 执行期 `create_dir_all` | **b**：目录是移动/复制的实现细节，Journal 只记文件操作；撤销后空目录残留可接受（§7.8 回滚语义不含目录删除） |
| 清单解析 | a) kernel 收原始文本自行解析；b) 壳层编码感知解析后传结构化行 | **b**：编码检测属壳层事实采集（ADR-0014 管道），kernel 保持纯函数、只做路径安全与计划 |

## 3. 选择理由

- **跨盘"复制→校验→删源"**：kernel Move 臂按 `same_volume` 分流——同盘走改名（瞬间完成），跨盘走 `copy` → `verify_move_integrity`（大小必须一致；两侧都能提供 blake3 时比对哈希，任一侧不支持则退化为大小校验，"校验不通过绝不删源"仍由大小把守）→ `remove_file(source)`。校验失败返回 E3005（retryable）并**尽力清除坏副本、绝不删源**——测试注入损坏副本验证了源保留与坏副本清理。
- **Journal 语义**：跨盘移动仍记 `Rename`（移动语义），撤销＝反向移动（§5.8"移动类回滚＝反向移动"）；反向移动跨盘由适配层 move 的复制兜底完成，目标副本被消费。复制类 reverse 维持既有"目标进隔离目录/备份还原"。
- **路径安全**：清单的名称与子目录均要求相对路径且不含 `..` 段（E1003）；kernel 再用 `is_under` 双重校验 source ∈ source_root、target ∈ target_root；target==source 按 E1002 阻断。"目标在源目录内部防自我递归"在文件粒度退化为该检查（目录级归档属 C08，见 ADR 关联）。
- **缺失项**：`skip`＝条目 blocked E2001＋resolution Skip（预览可见、执行期跳过）；`error`＝计划期整单 E2001 拒绝（列出首个缺失路径）。

## 4. 后果与退路

- **后果**：FsAdapter 新增 `same_volume`/`remove_file`/`create_dir_all` 三个可选能力（缺省 E5001/false，CliFsAdapter 已实现；WASM 适配按需实现）；`remove_file` 是首个"真删除"类适配器能力，仅限移动语义内部使用——审计上它只出现在跨盘移动之后，Journal 不单独记录；撤销后创建的空目录残留（可接受，与 §7.8 一致）。
- **退路**：若未来需要"移动后目录也清理"，在 C07 执行器追加空目录回收（记 Journal 或不记需另行评审）；`same_volume` 的 Windows 实现走卷序列号比对（与 ADR-0012 文件身份同源），当前 CliFsAdapter 复用 S01 的 `same_volume`（probe_root＋元数据）。
