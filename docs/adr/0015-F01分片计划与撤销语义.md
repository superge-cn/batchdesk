# 0015 F01 分片计划与撤销语义

- 状态：已采纳
- 日期：2026-10-30
- 关联：[设计 01 §5/§8](../design/01-内核接口与IPC契约.md)、[方案 v1.19 §5.1](../baseline/产品方案-v1.19.md)、[TC v0.3 F01](../testing/测试用例库-TC-v0.3.md)

## 1. 背景

F01「TXT 按文件大小分割」需要把一次源文件操作表达成多条产物。现有 `PlanAction`
只有 rename/move/copy/archive/extract/create-dir/transcode/edit-content/delete，没有
"由源区间生成新文件"的动作；若静默复用 `copy`，`expected` 指纹会按整文件大小复核
而分片长度不一致，撤销也无法区分"复制"与"分片"。

同时方案 §5.1 要求：只在行边界断开、超长行独占一片、无换行按字节硬切、目标值不设
固定下限、4 MB 量级块读取（不整文件入内存）。kernel 是纯函数层，不能读盘，边界计算
必须由壳层扫描结果驱动。

## 2. 决策

1. **动作与条目**：追加 `PlanAction::Split`（`"split"`）；每个分片一条 entry，共享
   `relation.groupId`、`role="output"`、`partIndex/partTotal`（对齐设计 01 §5 的 1:N
   语义）。`PlanEntry` 追加可选字段 `range{start,end}`，仅 split 使用。
2. **边界计算**：kernel 提供纯函数 `SplitAccumulator`（逐行字节长度驱动，内存 O(分片数)），
   壳层用 `platform::text::stream_segments` 逐行喂入，产出 `SplitLayout`；`plan_f01`
   只消费布局，不读盘、不取时钟。
3. **分片命名**：`原名.序号.扩展名`（序号按分片总数补零，如 `report.01.txt`）；序号
   规则来自方案 §5.1「原名＋序号」，分隔符与补零属工程细节，由本 ADR 定版。
4. **执行与撤销**：新增适配层原语 `FsAdapter::copy_range_atomic`（固定 64 KiB 块流式
   复制 `[start,end)`，临时文件＋原子改名）。split 的 Journal：forward=`WriteAtomic`
   （`dataRef` 省略）、reverse=`Quarantine`（新建产物进隔离目录）；目标已存在且选择
   覆盖时，按 copy 覆盖流程先 `backup_to_quarantine`，reverse=`WriteAtomic{dataRef}`。
5. **变更复核**：split 不用 `expected.size` 做整文件指纹（它是分片输出长度），apply
   期复核 `range.end ≤ 源文件当前大小`，不满足记 skipped + E2010。
6. **本切片边界**：只做源字节直通（`params.encoding="source-bytes"`），不转码；转码
   分片待后续切片，届时由同一 range 流式管线叠加解码/编码。

## 3. 后果

- `FsAdapter` 新增默认方法，未实现适配器返回 E5001；不静默降级为整文件读写。
- 分片数在 plan 期确定，预览可列出全部产物；plan 与 apply 之间源文件增长只可能让
  末片区间仍有效（区间不越界），缩小则整组跳过并提示重新规划。
- 撤销语义与 copy 新建保持一致，删除一律进隔离目录（不变量 7），不新增组级回滚。

## 4. 被推翻的条件

若后续切片引入"分片转码"或"分片与压缩/合并的复合计划"，需要重新评估 `range` 是否
应扩展为"源区间＋目标编码"结构；届时新写 ADR，不修改本篇正文。

## 5. 适用范围扩展（2026-10-30，F02/F03）

`split` 动作、`range` 字段、命名规则与撤销语义对 F02（按行数）与 F03（按份数）同样
适用，不新增动作或字段：

- **F02**：累加器增加 `SplitBasis::Lines`（每满 N 行收片，尾片保留，方案 §5.15）；
- **F03**：方案 §5.15 要求"必做行数预扫描"，壳层先扫一遍行数，再由纯函数
  `part_line_quotas(total_lines, parts)` 计算逐片行数配额（总行数÷份数取整，余数进
  前几片）；累加器以 `SplitBasis::Quota` 按配额收口，**最后一份配额不提前收口**，
  使预扫描后文件增长时多出的行并入尾片而不是产生额外分片。
- **份数超过总行数**：按行数封顶（每片至少 1 行，不产生空片），plan 追加
  `parts-exceed-lines` 谨慎级警告。
- 三种基准都沿用"源字节直通"，转码分片仍属后续切片。
