# 0022 F10 目录清单：摘要计划＋流式 CSV 写出

- 状态：已采纳
- 日期：2026-10-30
- 关联：[设计 01 §3.1/§5](../design/01-内核接口与IPC契约.md)、[设计 04 §4](../design/04-文件系统适配层契约.md)、[方案 v1.19 §4.8/§5.15](../baseline/产品方案-v1.19.md)、[TC v0.3 F10/E02](../testing/测试用例库-TC-v0.3.md)

## 1. 背景

F10「生成目录清单」要流式遍历目录树、不递归读内容，输出名称/大小/时间/层级
（方案 §5.15），并为 F11/C07 提供清单输入。工程上必须解决：

1. 十万级条目不能装进 `PlanDocument`，计划与执行必须分离；
2. 遍历发生在 apply 期，内核执行器不能直接读盘；
3. 目标清单文件不能把自己/临时文件列进去；
4. 占位文件、符号链接、不可读目录的跳过与计数；
5. 撤销必须复用 Journal，而不是功能自建删除。

## 2. 决策

1. **CSV 格式固定**：UTF-8 BOM＋`\n` 行尾，表头
   `相对路径,名称,类型,大小,修改时间,层级`；类型值为 `文件`/`目录`；
   相对路径以 `/` 分隔且不含根目录名；根目录直接子项层级为 1；目录大小写 0；
   修改时间为 RFC3339。输出编码遵循方案 §5.2 的 CSV 默认（UTF-8 BOM）。
2. **计划只存摘要**：`plan_f10` 每个根目录一条 `listing` entry（1:1），
   源=根目录、目标=清单文件；计划 payload/params 只带
   `format=csv/includeFiles/includeDirs/targetEncoding` 与摘要计数（文件/目录/
   占位/跳过/最大深度），不保存条目列表。计划期由平台 `inspect_tree` 流式扫描
   得到摘要，不生成清单内容。
3. **apply 流式写出**：新增 `DirectoryLister` 端口（内核纯接口），平台
   `FsDirectoryLister` 按目录逐层读元数据并写 CSV；新增
   `FsAdapter::write_atomic_with`，由适配层创建临时文件、调用流式 writer、
   flush 后原子改名，失败清理临时文件。条目逐行写出，内存只保留当前目录
   的候选列表，不缓存整棵树。
4. **目标不得在被列出的根目录内**：计划期与执行期均以规范化路径判断，
   命中返回 E1002。这样避免清单文件/临时文件被遍历进来；代价是不能把清单
   直接保存在被列出的目录（含根 `/`）内。
5. **跳过规则**：占位文件不写入清单并计数（`placeholders-skipped`，E02 仍为
   人工项）；符号链接与不可读目录跳过并计数（`unreadable-or-symlink-skipped`）；
   空目录输出仅表头并告警 `empty-directory`。计划期计数是预览摘要；apply
   期重新遍历，树变化时以 apply 实际结果为准，不按 E2010 拒绝（清单是快照）。
6. **目录顺序**：每个目录内按名称排序，深度优先；不跟随符号链接，不递归读
   文件内容；隐藏项按平台枚举原样包含。
7. **撤销/冲突**：`listing` 新建产物 forward=`WriteAtomic{dataRef:None}`、
   reverse=`Quarantine`；覆盖既有目标先 `backup_to_quarantine`，reverse=
   `WriteAtomic{dataRef}`。目标冲突仍走通用 `resolve_target`（默认 skip）。
8. **CLI**：`f10 --root <dir>... (--output | --output-dir)`，输出固定 UTF-8 BOM；
   `f10` 属实验功能切片命令，不构成 C40 冻结命令面（设计 13 §2.1）。

## 3. 后果

- 设计 01 §5 增加 `listing` 动作与 `plan_f10`/`DirectoryLister` 端口；
  设计 04 §4 增加 `write_atomic_with`；契约版本分别升至 v1.17/v1.6。
- F10 的 apply 不读文件内容，内存与目录深度/单目录宽度相关；满足 C-1
  十万级目录的流式遍历方向（实测基准待 C-1 台账）。
- 当前 C-1 性能、UI 预览、占位文件“单列”报告、执行中取消（单条 listing
  遍历内部的取消点）仍未落地；E02 继续按人工语料台账执行。
- 目标在被列出根内会被阻断；需要该布局时先输出到根外再移动/复制。
