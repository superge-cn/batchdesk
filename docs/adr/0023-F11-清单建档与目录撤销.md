# 0023 F11 按清单批量创建文件夹：逐级 create-dir 与空目录撤销

- 状态：已采纳
- 日期：2026-10-30
- 关联：[设计 01 §3.1/§5/§8](../design/01-内核接口与IPC契约.md)、[设计 04 §4](../design/04-文件系统适配层契约.md)、[方案 v1.19 §5.8/§5.15](../baseline/产品方案-v1.19.md)、[TC v0.3 F11/R01/E04](../testing/测试用例库-TC-v0.3.md)

## 1. 背景

F11「按清单批量创建文件夹」要求逐行解析清单、规范化路径、创建多级目录，并把
无效行集中报告（方案 §5.15、§5.8）。工程上必须解决：

1. 路径穿越与非法字符不能靠事后报错；
2. 多级目录创建必须可按 Journal 撤销，不能留下半成品父目录；
3. F10 生成的目录清单应能直接作为 F11 输入；
4. 清单本身可能含多种编码与无效行。

## 2. 决策

1. **清单输入**：支持 F10 CSV（表头含 `相对路径` 与 `类型`，只取 `类型=目录`/
   `dir` 的行）以及单列/首列路径清单（可选表头 `相对路径`/`路径`/`path`）。
   清单文件由壳层做编码检测（支持 `--source` 覆盖），转 UTF-8 后按 RFC 4180
   解析；解码失败 E3002，编码需人工确认 E3001。
2. **路径安全**：只接受相对路径；拒绝绝对路径、盘符/UNC、`..` 逃逸、空路径；
   每个路径分量复用 `conflict::validate_target_name`（非法字符/Windows 保留名/
   结尾点空格）。无效行不执行，按行号汇总为一个 `invalid-rows` 告警；重复路径
   去重并汇总 `duplicate-rows`。目标根必须已存在且为目录。
3. **逐级展开**：每条有效相对路径按父到子展开为多个 `create-dir` 条目，
   去重后写入同一 `PlanDocument`；条目 `source` 为空、`target` 为根下绝对路径，
   `expected` 省略。已存在目标按 `existing-target` + skip；受保护目标 E2009。
4. **执行与撤销**：`PlanAction::CreateDir` 每条只创建一级目录（`FsAdapter::
   create_dir`）；Journal forward=`CreateDir{path}`、reverse=`RemoveDir{path}`。
   撤销按 Journal 逆序调用 `remove_dir_if_empty`，非空目录失败并报告，不递归删除。
   计划展开保证父目录条目先于子目录；创建失败时已成功条目仍可由 Journal 回滚。
5. **CLI**：`f11 --list <csv> --root <dir> [--source ENC]`；`f11` 属实验功能切片
   命令，不构成 C40 冻结命令面（设计 13 §2.1）。
6. **无效行/缺口**：清单中的父路径若已是文件、目标根不存在、预检 E04、取消、
   超长路径矩阵仍在后续切片；当前 CLI 只探测最终目标是否已存在，父级文件冲突
   会在 apply 失败并由报告暴露。

## 3. 后果

- 设计 01 §3.1/§5/§8 增加 `plan_f11`、`create-dir` 的 F11 语义与
  `CreateDir/RemoveDir` Journal 操作；设计 04 §4 增加 `create_dir`/
  `remove_dir_if_empty`；契约版本升至 v1.18/v1.7。
- 计划条目数按路径层级展开，深层清单会产生更多条目；换来可逐级撤销、不误删
  既有父目录。
- F10→F11 的清单链路已打通；F11 仍为切片，无 UI、无 C-1 基线、无 E04 预检接线。
