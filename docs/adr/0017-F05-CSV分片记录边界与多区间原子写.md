# 0017 F05 CSV 分片：记录边界、表头重复与多区间原子写

- 状态：已采纳
- 日期：2026-10-30
- 关联：[设计 01 §3.1/§5](../design/01-内核接口与IPC契约.md)、[方案 v1.19 §5.3](../baseline/产品方案-v1.19.md)、[TC v0.3 F05/T01/T02/T04/K08](../testing/测试用例库-TC-v0.3.md)

## 1. 背景

F05「CSV 分割」要求按大小或行数切分，默认每片保留表头，且必须按**记录边界**
断开（方案 §5.3）。与 F01–F03 的纯文本分片相比有三个工程差异：

1. CSV 记录可能含引号内换行，按物理行切分会把一条记录拆成两片；
2. 每片都要重复表头，因此分片产物大小 ≠ 源区间长度，不能用单区间复制；
3. 列数漂移、引号不闭合、编码不统一需要"提示但不猜测"的处理口径（T01/T02/T04/K08）。

## 2. 决策

1. **记录扫描在 kernel 纯状态机**：`CsvRecordScanner` 按块喂字节、跨块保持引号
   状态，实现 RFC 4180 记录边界（`""` 转义、引号内换行、CRLF）；壳层只负责读盘。
   该状态机不读盘、不取时钟，符合不变量 1。
2. **分隔符嗅探在 kernel**：`sniff_delimiter(sample)` 对 `,` `;` Tab `|` 四个候选
   做记录扫描，取"多列记录最多且列数最稳定"的候选；样本由调用方显式给出窗口。
   嗅探失败时按逗号兜底并产出 `delimiter-not-detected` 告警，允许 `--delimiter`
   手动覆盖（方案 §5.3）。
3. **复用 `split` 动作 + 追加式 `csv` 载荷**：不新增 `PlanAction`。`PlanEntry.range`
   记**记录区间**（不含表头），新增可选字段
   `csv{header?, delimiter, rows, dirtyRows}`；`header` 是源文件表头区间，每片先写
   表头再写记录。旧计划不含 `csv` 时反序列化为 `None`，F01–F03 行为不变。
4. **多区间一次成文件**：`FsAdapter` 追加 `copy_ranges_atomic(source, ranges[],
   target, policy)`，平台实现为"打开源文件一次、按序写临时文件、一次原子改名"；
   默认实现返回 E5001，适配层不支持时明确拒绝、不静默降级。无表头时仍走既有
   `copy_range_atomic`，保持兼容。
5. **表头策略**：v1 只支持单行表头。首条记录即表头（默认每片重复）；首条记录
   含引号内换行即视为多行表头，计划条目 `blocked` E3004（不猜测、不自动合并）。
   `--no-keep-header` 可关闭重复，此时首条记录按数据行处理，列数基准取其列数。
6. **异常口径**：引号不闭合至文件尾 → 剩余字节按末条记录保留并告警
   （`unclosed-quote`，Danger，T01）；记录列数与表头不一致 → 逐片与总计计数上报
   （`column-drift`），**不静默修正**（T04）；空文件、仅表头不产生
   分片并告警；UTF-16 源（含 BOM 或无 BOM 判定）在平台侧短路为占位布局，计划条目
   `blocked` E3001 并提示先走 C01 转码（K08）。UTF-8/GBK 等记录边界由 ASCII 字节
   标记的编码按**源字节直通**，产物编码与 BOM 跟随源文件（表头重复时 BOM 随表头重复）。
7. **计量口径**：字节基准只计记录区间字节（表头不重复计入目标值）；每片偏差最多
   一条记录；单条记录超过目标值时独占一片（每片至少一条记录）。行数基准计**逻辑
   记录数**（不含表头），避免引号内换行被重复计数。
8. **变更复核**：apply 校验 `header.end ≤ range.start` 且两者都 `≤` 源文件当前
   大小；任一不满足记 skipped + E2010，不产生半成品。

## 3. 后果

- 设计 01 §5 增加 `csv` 载荷与 F05 的 `expected` 口径；契约版本升至 v1.11。
- 多区间写要求适配层实现 `copy_ranges_atomic`；内存/测试适配器已同步实现，
  Web/WASM 适配器接入前 F05 在 Web 版不可用（桌面壳可用）。
- 字节基准按记录区间计量，用户看到的产物总大小会因表头重复而大于源区间之和；
  预览需展示"header repeated"字样，避免误解。
- UTF-16 支持以 C01 转码为前提；F05 本身不做转码（与 F01–F03 的源字节直通一致）。
- 分隔符嗅探只基于头部样本窗口；采样窗口由调用方显式传入，不在此发明数值阈值。
