# 0019 F07 CSV 抽取指定列：列选择、表头规范与 1:1 产物

- 状态：已采纳
- 日期：2026-10-30
- 关联：[设计 01 §3.1/§5](../design/01-内核接口与IPC契约.md)、[方案 v1.19 §5.15](../baseline/产品方案-v1.19.md)、[TC v0.3 F07/T08](../testing/测试用例库-TC-v0.3.md)

## 1. 背景

F07「CSV 抽取指定列」要求按列名或列序号导出子集并保留原行序（方案 §5.15），
风险点是**列名重复或含特殊字符**。与 F05/F06 不同，F07 是 1:1 变换：每个输入
文件产出一个新文件，源文件不变；撤销只需删除产物。工程上必须定义：

1. 列选择的表示与输出顺序；
2. 表头规范化、重复列名与列不存在的处理；
3. 无表头文件的定位规则；
4. 行宽漂移、编码与 BOM、撤销语义。

## 2. 决策

1. **新增 `csv-extract` 动作**：不复用 `edit-content`（就地改写，且禁止 target）
   或 `copy`（内容不变）。F07 每个输入一条 entry（1:1），`PlanEntry` 追加可选
   载荷 `csvExtract{encoding,size,delimiter,hasHeader,columns,columnCount,
   selections,targetEncoding,invalid,dirtyRows}`；`selections` 为已解析的 0-based
   字段序号与规范化列名，输出顺序即用户选择顺序。
2. **列名规范化后匹配**：沿用 F06 的 `normalize_header_name`（剥 BOM、trim）。
   名称选择命中多个同名列时**取首次出现**并给出 `duplicate-column-name` 告警；
   要选择另一同名列必须改用 1-based 列序号。列名未命中或序号越界按 E3004 阻断，
   不静默补空。
3. **1-based 对外序号**：CLI `--column-index N` 与用户界面口径为 1-based；
   计划载荷存 0-based 索引，避免执行层再做换算。
4. **同一列重复选择是非法参数**：按名称与按序号解析到同一字段时报 E1002，
   "子集"不允许重复列。空选择报 E1001。
5. **无表头只允许列序号**：显式 `--no-header` 时按列序号抽取，名称选择按 E3004
   阻断；有表头与无表头混用按 E1002 拒绝。输出在无表头时**不写表头行**；
   有表头时写所选列的表头（规范化名），数据行按同一选择顺序输出。
6. **行序与行宽**：数据行严格保持原顺序；行字段数少于所选序号时该位置写空字段，
   多余字段忽略，脏行数在计划载荷与告警中计数（不静默修正）。
7. **输出编码必须显式**：`targetEncoding` 必填，沿用 F04/F06 的 `transcode` 路径；
   输入先解码到 UTF-8 解析，输出再编码，BOM 只在产物开头写一次。输出分隔符沿用
   输入分隔符（本切片不提供输出分隔符开关）。
8. **apply 复核与撤销**：逐输入复核普通文件、占位、保护目录与源大小（`expected`
   `algorithm="size"`，变化 skipped + E2010）；执行期重新规范化表头并与计划载荷
   逐项比较，变化报 E2010（条目 failed，不写半成品）。Journal
   forward=`WriteAtomic{dataRef:None}`／reverse=`Quarantine`；覆盖既有目标时先
   `backup_to_quarantine`、reverse=`WriteAtomic{dataRef}`。
9. **CLI 输出模式**：`--output` 仅允许单输入；`--output-dir` 可多输入，文件名沿用
   源文件名；两种模式互斥。批量目标重名在计划期拒绝（E1002），已存在目标按
   `existing-target` + 默认 skip 处理。

## 3. 后果

- 设计 01 §5 增加 `csv-extract` 动作与 `csvExtract` 载荷；契约版本升至 v1.13。
- 表头名重复时按名称只能取首列，第二列需用序号；这是可见行为，预览与 CLI
  帮助必须说明。
- 当前 apply 整文件读入并转码，内存为 O(单输入 + 产物)；大文件流式抽取与
  逐文件进度仍为缺口。
- 输出统一用 `\n` 行尾并由 `write_record` 按需要加引号；源文件的 CRLF 不会保留。
  需要保留原样换行时先走 C02 或后续版本扩展。
