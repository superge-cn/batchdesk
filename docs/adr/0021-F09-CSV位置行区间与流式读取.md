# 0021 F09 CSV 抽取指定位置行：区间计划与只读区间执行

- 状态：已采纳
- 日期：2026-10-30
- 关联：[设计 01 §3.1/§5](../design/01-内核接口与IPC契约.md)、[设计 04 §4](../design/04-文件系统适配层契约.md)、[方案 v1.19 §5.15](../baseline/产品方案-v1.19.md)、[TC v0.3 F09/T02](../testing/测试用例库-TC-v0.3.md)

## 1. 背景

F09「CSV 抽取指定位置行」要求取第 X 至 Y 行，跳过前段且不整读文件
（方案 §5.15）。它与 F08 的「前/后 N」同属按数据记录抽取，但多出两个工程约束：

1. 必须知道选中记录在源文件中的字节边界，执行时才能跳过前段并提前停止；
2. 引号内换行必须仍按**一条记录**计数，不能按物理行计数（T02）；
3. X/Y 可能越过实际行数，预览要给出明确告警；
4. 既有 `generic_apply` 的 CSV 1:1 路径整文件读入，不能直接复用于 F09。

## 2. 决策

1. **X–Y 语义**：均为 1-based **数据记录**序号（不含表头）；`X=0` 或
   `Y<X` 按 E1002 拒绝。无表头时第 1 条记录即数据行 1；有表头时数据行从
   表头之后开始。记录计数沿 `CsvRecordScanner`，引号内换行不增加记录号。
2. **复用 `csv-rows` 动作与 `PlanCsvRows` 载荷**：不新增 `PlanAction`。载荷追加
   `startRow/endRow/headerRange/dataRange/totalKnown`；`window="range"`，
   `count` 为实际选中行数。旧计划缺省这些字段仍按 F08 first/last 工作。
3. **计划期提前终止**：`platform::csv_range_layout` 逐段扫描记录，扫到第 Y 条
   数据记录即返回（`totalKnown=false`）；只有 Y 越过实际行数（或 X 越过）时才
   继续到 EOF，从而给出 `range-exceeds-rows` 告警并得到真实总数。
4. **只读区间执行**：计划记录表头区间与选中数据区间；apply 通过新增的
   `FsAdapter::read_ranges(source, ranges)` 只读取这些区间，不调用
   `read_bytes` 整读源文件。读取的原始字节按源编码解码、按目标编码重写，
   行尾保持源字节形态（CRLF 不被改写），BOM 策略沿用目标编码。
5. **apply 复核与撤销**：`expected.size` 为源文件大小；`read_ranges` 在区间
   越界/文件缩短时返回 E2010；有表头时重新解码表头并与计划 `columns`
   比较，变化 E2010、不写半成品。Journal forward=`WriteAtomic{dataRef:None}`／
   reverse=`Quarantine`；覆盖既有目标时先备份、reverse=`WriteAtomic{dataRef}`。
6. **阻断与告警**：UTF-16 源 E3001（提示先走 C01）；多行表头 E3004；
   编码未确认 E3001；Y/X 越界 `range-exceeds-rows`（Caution）；选中行字段数
   与表头不一致 `csv-row-width-mismatch`；不闭合引号 `unclosed-quote`；
   分隔符嗅探失败 `delimiter-not-detected`；空文件/仅表头分别告警。
7. **CLI**：`f09 --start X --end Y`，`--output` 仅单输入、`--output-dir` 可多输入；
   沿用 F07/F08 的 `--target/--source/--delimiter/--no-header/--invalid/
   --sample-bytes/--protected-dir/--json`。`f09` 属实验功能切片命令，不构成
   C40 冻结命令面（设计 13 §2.1）。

## 3. 后果

- 设计 01 §5 扩展 `csvRows` 载荷并新增 `plan_f09`；设计 04 §4 增加
  `read_ranges` 能力；契约版本分别升至 v1.16/v1.5。
- F09 apply 不再整读源文件，但仍将**选中区间**读入内存后再转码；选中窗口很大时
  内存为 O(选中区间 + 产物)，后续可改为流式转码/直接区间复制。
- 计划期在 Y 正常命中时提前停止；Y 越界时仍需扫到 EOF（为了给真实越界告警）。
- 与 F08 的差异：F09 保留源行尾/原始记录字节（经转码），F08 仍规范化输出 `\n`；
  这是 F09 的显式行为，不是 F08 的静默修复。
- 有表头时输出表头沿用源表头区间；无表头且 X>1 时输出不含源 BOM，目标 BOM
  只由 `targetEncoding` 决定。
