# 验收签署单模板（TS）

> **文档信息**：TS v0.2 ｜ 日期 2026-10-28 ｜ 上游：T v1.12（§4 四级验收、§5.3 缺陷关闭、§6.2 冒烟）＋《办公辅助工具产品方案》v1.19（§12.5 版本通道、§12.6 毕业五项）｜ 性质：可复制的空白表单集
>
> **v0.2 修订（2026-10-28）**：新增模板 I（AI 安全签署单，F15 Phase 1/2/3）。
>
> **用途**：为 T §4 的每一次签字提供**统一表单与证据字段**，避免各阶段自造格式导致验收结论无法横向比较。
>
> **不复制基线**：各模板只列"核验项名称＋回指章节"，判定口径以 T §4 原文为准；本文件不转抄判定条件段落。
>
> **结论纪律**：签署结论只允许"通过／不通过"（T §4.4），不设"有条件通过"；豁免只在 T §4.2 允许的范围内签发（模板 F），毕业验收（模板 D）不接受任何豁免。

## 1. 通用填写规则

| 项 | 规则 |
|---|---|
| 构建号 | 按方案 §12.5 的 `1.x` 序列与 B/C 通道标注（如 `1.0.0-B3`） |
| 环境组合 | 必填 T §6.1 的 M1–M8 编号；跨组合结论须至少两个组合 |
| 用例引用 | 用 TC 编号（[测试用例库](./测试用例库-TC-v0.2.md)）；异常用例带 `@语料编号` |
| 证据 | 截图／日志／产物清单或哈希，文件名须含用例 ID；证据不入库，归档到项目文档库 |
| 缺陷引用 | 缺陷编号格式 `BUG-{功能编号}-{序号}`；级别按 T §5.1 |
| 阻塞 | 写明阻塞类型（环境／数据集／裁决）＋T 附录 A 编号 |
| 签字 | 手写或电子签均须含姓名、角色、日期；角色不可代签 |
