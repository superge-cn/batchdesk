## 1. 库结构与编号

### 1.1 三层结构

| 层 | 内容 | 落点 |
|---|---|---|
| 配方层 | 可复用的步骤骨架与断言要求（§2） | 一次定义，全功能共用 |
| 实例层 | `编号 + 配方 + 参数` 的具体用例（§3、§4） | 每条有唯一 TC 编号 |
| 记录层 | 执行结果与证据（由执行人填写） | §5；签署走 [验收签署模板](./验收签署模板-v0.2.md) |

**实例展开规则**：每个功能行给出实例序号段（如 `01–04`），实例 ID 形如 `TC-F01-PRE-02`。每条实例＝对应配方的通用步骤＋该功能行的参数与专属判定点；**参数与判定点两者缺一不得执行**。

### 1.2 编号与类型（承接 T §2.3）

| 项 | 规则 |
|---|---|
| 主格式 | `TC-{功能编号}-{类型}-{序号}` |
| 类型 | `PRE`（预览）/ `EXE`（执行）/ `RBK`（回滚）/ `XCT`（横切）/ `NEG`（负面） |
| 异常挂接 | ID 后追加 `@语料编号`，如 `TC-F05-EXE-02@T01` |
| 承诺验证 | 类型后加 `-PV`（Web 专项，本库不使用；见 TW 分册） |
| 序号 | 两位，按配方顺序（01 = 主配方），作废不复用 |

### 1.3 配方代码

| 代码 | 名称 | 适用 |
|---|---|---|
| P1–P4 | 正常预览／参数边界／危险与冲突标注／预览失效 | 全部 PRE 实例 |
| P5 | 空输入、单文件、巨输入 | 按功能行选用 |
| P6 | 预检项与保护名单（S01/S02 专用） | S01/S02 PRE |
| E1–E5 | 正常执行／异常语料／冲突策略／任务控制／大输入与边界 | 全部 EXE 实例 |
| E○1–E○2 | 简化执行（仅关键判定） | ○ 功能（C05/C18/S01/S02） |
| R1–R3 | 立即撤销／部分回滚与窗口／撤销异常 | 全部 RBK 实例 |
| R○1–R○2 | 简化回滚（仅关键判定） | ○ 功能（C05/C18/S01/S02） |

> **序号超过 04 的说明**：C05/C18 的 PRE `05–06` 是配方参数变体——C05 取 P3/P4 的冲突矩阵抽样与刷新，C18 取 P5 的重复预览幂等与巨输入；S01/S02 的 `01–06` 全部按 P6 展开。

## 2. 用例配方

### 2.1 通用前置与证据规则

- **环境组合必填**：按 T §6.1 的 M1–M8 填写；跨组合结论须至少两个组合（T §6.1 标注规则）。
- **数据集**：`C-1…C-8`（T 附录 C）或语料编号（T §3.2）；自造样本须写明构造参数。
- **证据**：截图 **或** 日志片段，异常用例附语料编号；写操作须附产物清单或哈希。
- **判定点写法**：`章节号：判定点摘要`；无出处时**不写预期**，登记 T 附录 A 并把用例标"阻塞"。

### 2.2 预览配方（PRE）

| 代码 | 步骤骨架 | 必须断言 | 出处 |
|---|---|---|---|
| P1 | 选正常输入 → 填合法参数 → 触发预览 | ① 影响范围统计（条目数/体积/目标路径）与逐项差异可见；② 预览期间目标目录快照前后一致（零落盘）；③ 可退出预览 | 方案 §7.1、§7.4 |
| P2 | 参数取该功能区间的最小值、最大值与临界±1（区间原文见对应章节） | ① 边界内预览成功且统计随参数变化；② 越界给出拦截提示、不产生预览；③ 区间未定义项标"阻塞" | 方案对应章节；T §2.1 边界值 |
| P3 | 构造危险项：目标重名、覆盖已有文件、非法名、保护名单命中 | ① 危险级/冲突标注逐项可见（重名、非法字符、覆盖对象）；② 未选冲突策略时执行入口阻断或要求显式选择；③ 安全默认不覆盖 | 方案 §7.4、§7.7、§4.5 |
| P4 | 预览后修改参数、换输入集合或切换通道（桌面版无通道，此项仅参数与输入） | ① 旧预览立即失效；② 直接执行被阻断并提示重新预览 | 方案 §7.3 |
| P5 | 空目录/空清单、单文件、C-1 或 C-2 级输入 | ① 空输入给出提示而非异常；② 单文件路径可走通；③ 巨输入预览完成且不整读文件（三档策略） | 方案 §4.8 |
| P6 | 仅 S01/S02：逐项触发预检项或保护名单判定 | ① 预检项逐项有结论（通过/警告/阻断）；② 名单命中给出明确阻断理由；③ 不可达项按降级提示且不阻塞 | 方案 §3.3、§4.9、§9.2 |

### 2.3 执行配方（EXE）

| 代码 | 步骤骨架 | 必须断言 | 出处 |
|---|---|---|---|
| E1 | 用 P1 已确认的预览直接执行 | ① 产物数量/命名/内容与预览一致；② 编码、行边界、表头等该功能核心规则成立；③ 进度事件齐全（项级＋总量级） | 方案 §7.5；功能行判定点 |
| E2 | 执行同一功能并挂指定语料 | 断言以 T §3.2 该语料行"预期行为"为准（本库不复制） | T §3.2 对应行 |
| E3 | 构造点名/覆盖/非法目标，按 C19 的四策略各执行一次 | ① 四策略行为与方案一致；② 无静默覆盖；③ 策略变更后需重新预览 | 方案 §7.7、§4.5、§7.3 |
| E4 | 执行中暂停、恢复、取消各一次；再对失败项重试 | ① 暂停点可控、进度不倒退；② 取消后已完成项状态可查、未完成项无半成品；③ 重试仅作用于失败项 | 方案 §7.5、§7.6、§9.3 |
| E5 | 用 C-2／T06／T03／C-1 级输入执行 | ① 内存占用不随输入线性增长（流式）；② 超长行/超大单行按方案处理且有告警；③ 产物无截断 | 方案 §4.8、§5.1、§5.3 |
| E○1 | 简化：只跑"正常执行"一次 | 断言该功能最关键判定成立（功能行指定） | 功能行判定点 |
| E○2 | 简化：只跑一次阻断/失效/取消路径 | 断言阻断或失效生效且零副作用 | 功能行判定点 |

### 2.4 回滚配方（RBK）

| 代码 | 步骤骨架 | 必须断言 | 出处 |
|---|---|---|---|
| R1 | 执行成功后立即撤销 | ① 产物恢复原状或新增产物被移除；② 依据映射表/Journal 反查，非功能内自建撤销；③ 撤销后有日志记录 | 方案 §7.8 |
| R2 | 构造部分失败任务后撤销；再验证窗口边界 | ① 仅回滚成功项，失败项保持原状；② 窗口内可撤销、窗口外按方案判定（可撤销期默认值与可配区间见方案 §7.8、11.6-14） | 方案 §7.8 |
| R3 | 撤销时让目标被占用/只读/已被第三方改动 | ① 给出明确失败原因且不清空映射；② 不造成二次破坏；③ 提示满足三层结构 | 方案 §7.8、§4.6 |
| R○1 | 简化：只验"有可撤销依据" | 断言映射/Journal 可查，入口可达或按设计不可达 | 功能行判定点 |
| R○2 | 简化：只验"阻断/失效后零副作用" | 断言未产生任何写操作 | 功能行判定点 |

> **配方与 T §2.2 硬约束的关系**：○ 功能只用 E○/R○，不得因"简化"跳过关键判定；批量写功能的任一环节缺失即按 T §2.2 硬约束判不通过。

## 5. 状态、执行记录与维护

### 5.1 用例状态机

| 状态 | 含义 | 迁移条件 |
|---|---|---|
| 设计 | 已编号、参数待确认 | 参数与判定点齐备 → 就绪 |
| 就绪 | 可执行 | 开始执行 → 执行中 |
| 执行中 | 正在跑 | 有结论 → 通过/失败；环境缺失 → 阻塞 |
| 通过 | 实测符合判定点 | 构建变更或判定点修订 → 就绪（重跑） |
| 失败 | 实测不符 | 按 T §5.2 判缺陷或需求变更 |
| 阻塞 | 缺环境/缺数据集/裁决未定 | 阻塞原因消除 → 就绪 |
| 作废 | 设计失效 | 保留编号，不复用 |

**阻塞必填**：阻塞类型（环境／数据集／裁决）＋对应 T 附录 A 编号（如 A-01、A-03、A-12）。**裁决类阻塞已清零**：A-02／A-09 于 2026-10-28 裁决（收于方案 v1.8），A-01／A-03–A-08／A-10–A-12 同日裁决（收于方案 v1.9），相关用例全部转"就绪"；此后仅剩环境与数据集两类阻塞。

### 5.2 执行记录

- 按 T §2.3 六列记录：用例 ID、前置条件、步骤、预期结果、实际结果、证据。
- 实际结果只允许"通过／失败／阻塞＋实测值"，**禁止模糊表述**。
