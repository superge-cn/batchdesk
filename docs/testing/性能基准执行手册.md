## 2. 环境与前置

1. 使用 **release 构建**（`cargo build --release`）；记录提交 SHA、构建号、Rust 工具链。
2. 先填写 C-4 环境台账：介质型号、文件系统、剩余空间、磁盘压缩/索引、实时杀软状态。
3. C-5 另填：UNC 路径、限速值、断线方式、探测超时（引 §4.9，不在本手册复述数值）。
4. 跑 C-2 前确认磁盘余量 ≥ 数据集体积 + 输出体积 + 安全余量（判定式引 §9.1）。
5. 关闭无关后台任务；同一轮内不更换机器/介质/文件系统。

## 3. 运行协议

- **预热**：每个场景先跑 1 次丢弃结果（WASM/磁盘缓存/杀软冷启动都会影响首轮）。
- **重复**：同一场景连续跑 3 次，取中位数；记录全部 3 次原始值，不只记中位数。
- **隔离**：不同数据集之间清理 `out/` 与临时目录；不要在 C-1 与 C-2 之间复用缓存结论。
- **证据**：记录命令、数据集生成命令与哈希、输出目录、日志、环境台账编号。
- **失败**：记录失败阶段（生成/读取/执行/写回）、错误码、是否可重试；不把失败样本混入中位数。
