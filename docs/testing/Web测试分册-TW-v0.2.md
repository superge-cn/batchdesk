## 1. 范围与不做

**测**（承接 T §1.1 Web 行）：

- 核心子集功能用例（方案 §13.4 的子集范围）在双通道下的行为；
- 双通道切换全流程（§13.10.1）、通道记忆与 `cloudAvailable` 置灰（02 §3.3）；
- OPFS／WASM 能力探测与降级链（§13.3/§13.4/§13.6）；
- 三条隐私承诺的**反向验证**（§13.10.1）与 §13.9 不承诺项负面用例；
- 文案一致性 NEG（T R-T08：撤销/日志入口不得暗示与桌面版等价，§13.8）；
- 云端 REST 契约（02 §4）与错误码（E1006/E4004/E5001–E5008/E5012）。

**UI 国际化**：Web Phase 3 复用 T v1.12 B8 / TC 的 I18N-01…08；F15-lite 不涉及。

**不测**（承接 T"Web 版不测"与 §13.9）：桌面版专有能力（UNC、保护目录、隔离目录、Journal 撤销、SQLite 日志）；商用授权（F14 并入授权模块）；真实云服务的容量与费用行为；**F15 Phase 1/2（桌面专属；Web AI Phase 3 见 TW-G）**。

## 2. 浏览器与环境矩阵（草案）

> §13.3／§13.9 定义浏览器能力与降级边界；**具体浏览器版本清单在其定稿前属草案**，本表只锁矩阵结构，候选列随 §13.3／§13.9 定稿校准（不发明正式值）。

| 维度 | 取值（草案） | 说明 |
|---|---|---|
| Chromium 系 | Edge（Win 主档）／Chrome | 主交付平台为 Windows（方案 11.6-4 已确认：MVP 仅 Windows 10/11） |
| 非 Chromium | Firefox ／ Safari | 至少各 1 个近版；Safari 覆盖 macOS |
| 网络态 | 在线／断网（本地任务必须可完成，§13.2） | 断网仅跑本地通道 |
| OPFS | 可用／不可用（模拟） | 不可用走降级链（§13.4），断言 E5003 路径 |
| WASM | 支持／受限（模拟） | 受限断言 E5002 与 §13.4 降级文案 |

环境类构造依赖真实浏览器与服务端 staging → 本册用例默认**人工执行**；TW-E 标注"自动化候选"的条目走 mock 服务端进 CI。
