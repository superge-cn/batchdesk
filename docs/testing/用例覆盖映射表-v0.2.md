## 4. 复算与再生成

**CSV 由脚本生成**：`python3 scripts/gen_case_map.py`（数据表在脚本内，逐行证据来自当次实测的测试名与语料台账）。改槽位/锚点/缺口请改脚本后重跑，再跑下面两个校验；直接手改 CSV 会让脚本与数据漂移。

```bash
# 行数与唯一实例 ID 必须等于 TC v0.3 §3.1 的 296
python3 - <<'EOF'
import csv, collections
rows = list(csv.DictReader(open('docs/testing/用例覆盖映射表-v0.2.csv', encoding='utf-8')))
assert len(rows) == 296, len(rows)
assert len({r['实例ID'] for r in rows}) == 296
print(collections.Counter(r['状态'] for r in rows))
EOF
```

```bash
# 锚点实名校验：CSV 里写的每一个测试名都必须真实存在，且不允许省略式写法
python3 - <<'EOF'
import csv, re
rows = list(csv.DictReader(open('docs/testing/用例覆盖映射表-v0.2.csv', encoding='utf-8')))
af = set(re.findall(r'(?m)^\s*fn ([a-z0-9_]+)\(\)', open('crates/cli/tests/apply_flow.rs', encoding='utf-8').read()))
cor = set(re.findall(r'(?m)^\s*fn ([a-z0-9_]+)\(\)', open('crates/kernel/tests/corpus.rs', encoding='utf-8').read()))
bad = [(r['实例ID'], n) for r in rows for n in re.findall(r'apply_flow::([a-z0-9_]+)', r['自动化锚点']) if n not in af]
bad += [(r['实例ID'], n) for r in rows for n in re.findall(r'corpus\.rs::([a-z0-9_]+)', r['自动化锚点']) if n not in cor]
bad += [(r['实例ID'], 'ellipsis') for r in rows if '…' in r['自动化锚点']]
bad += [(r['实例ID'], '状态/载体不一致') for r in rows
        if (r['状态'] == '🔶' and 'WebDriver' not in r['载体'])
        or (r['状态'] == '⛔' and r['载体'].startswith('CI'))]
assert not bad, bad
print('锚点实名与状态-载体一致性校验通过')
EOF
```

**逐行证据来源**（生成时均为当次实测，不引记忆）：`crates/cli/tests/apply_flow.rs` 的 66 项集成测试名；`crates/kernel/src/*.rs` 每模块 `#[test]` 计数（split 28、csv 18、generic_apply 40、apply 15、encoding 11、rename 10、regex_rename 11、archive 9、preflight 9、preview 4、duplicate 9、plan 21、conflict 9、journal 5、create_dirs 7、listing 6 等）；`crates/platform/src/*.rs`（fs 11、text 19、scan 10、config_store 13、csv_range 8、preflight 7、oplog 5、listing 4、csv_merge 6、csv 6、line_endings 3、replace_content 3、archive 3、journal 2）；`crates/kernel/tests/assertions.tsv` 的 24 条语料台账（19 asserted／4 partial／1 pending）；`src-tauri` 17 项壳层测试名；`fixtures/corpus/manual-only.txt` 的 4 条人工语料。
