## 4. 复算与门禁

```bash
# 改数据只改生成脚本，然后重跑＋校验
python3 scripts/gen_case_map.py && python3 scripts/check_docs.py
```

`check_docs.py` 对本表强制九项（CI 的 lint job 必跑）：① 行数＝296；② 实例 ID 唯一；③ 锚点列里 `generic_apply::tests::*`／`apply_flow::*`／`corpus.rs::*` 的测试名必须在源码中存在；④ 禁止省略式写法（"…"）；⑤ ✅ 行不得挂缺口；⑥ ⛔ 行不得标 CI 载体；⑦ ✅／◐ 行不得标"真人工"载体；⑧ 🔶 行的载体列须注明 WebDriver；⑨ E4 且 ✅ 的行必须引用取消类锚点（`cancel_rolls_back*`／`cancel_mid_batch*`／`task_state_events_cover_pause_resume_and_queued_cancel`／`e2e-tauri`）。

**逐行证据来源**（生成时均为当次实测，不引记忆）：`cargo test --workspace --all-features` 共 **572 项**（kernel 单测 376＋语料断言 22＋platform 98＋CLI 6＋CLI 集成 70）；`cargo test --manifest-path src-tauri/Cargo.toml` **23 项**；`pnpm test`（Vitest）**12 项**、`pnpm test:e2e`（Playwright＋Chromium）**14 项**；`crates/kernel/tests/assertions.tsv` 的 24 条语料台账（19 asserted／4 partial／1 pending）；`fixtures/corpus/manual-only.txt` 的 4 条人工语料。
