## 使用纪律

1. **只读**：本目录的基线文档不在此处编辑。修订在基线文档的原始载体上进行，改定后整体替换本目录的文件并同步更新上表的版本号。
2. **升版即同步**：基线升版后，仓库内引用其编号的文档（README、CONTRIBUTING、`docs/adr/`、`fixtures/README.md`）须做一次引用核查——章节号可能因重排而失效。
3. **不重复定义数值**：性能阈值一律引方案 §9.1，Web 端大小阈值一律引 §13.10.2；本仓库任何文档不出现第二处数值来源。
