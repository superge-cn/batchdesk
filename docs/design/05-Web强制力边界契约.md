## 0. 结论先行（三条，其余章节均为其展开）

1. **Web 版的强制力只存在于云端服务端**：本地模式（WASM）对授权与配额**零强制力**——不拦截、不放行、不判档，只做显示。
2. **`web/` 不含任何判定逻辑**：前端只能依据内核/服务端已给出的结果做显示、隐藏、置灰与文案，不得自行推导"能不能用"。
3. **WASM 公开导出面不暴露授权／配额判定入口**：导出面只含处理类入口与能力查询，判定类符号不得出现在导出表中（可被 `wasm-objdump`/符号表核查）。

**依据的原文**：方案 §13.5 复用边界表的"授权与配置｜不复用｜见 13.8"一行；§13.8"但**仍按同一 `LicenseService` 接口注入配额型实现（QuotaBased）**——保持桌面、单机、Web 三形态共用一套抽象，只换实现；其授权按云端配额口径单独设计"；AGENTS 不变量 11"**web/ 与 WASM 产物零强制力**：授权相关元素只做显示／隐藏，不得含放行／拦截逻辑，WASM 公开导出面不得暴露授权／配额判定入口；浏览器内一切判定均可被绕过、不得当作安全边界"。（"安全能力全层级免费"经 §13.8 转述引 §3.1，本篇不改写其原文。）

## 1. 术语：什么是"强制力"

| 术语 | 定义 | 判据（一句话自查） |
|---|---|---|
| **强制力** | 某个判定结果**必须被遵守**、绕过即失败的能力 | 把该判定删掉，用户能否继续操作？能 → 无强制力 |
| 显示控制 | 依据已有结果改变**可见性与可点性** | 改的是 `hidden`/`disabled`/文案，不是数据 |
| 能力降级 | 环境不具备某能力时返回错误码（E5001/E5002/E5003） | 依据是**环境探测**，不是授权 |

**边界**：能力降级属于内核职责（01 §1/§3、02 §3/§5），**不属于授权判定**；两者在实现中必须可区分——授权相关分支一律读 `LicenseService`，能力相关分支一律读 `BrowserCapabilities`／适配层能力声明。

## 2. WASM 公开导出面：白名单与黑名单

**允许导出**（与 IPC 命令层同构，仅处理类）：

| 类别 | 示例 | 说明 |
|---|---|---|
| 处理入口 | plan / apply / preview / cancel / journal 查询 | 与桌面版同一套内核能力，签名只依赖 DTO 与参数 |
| 能力查询 | `BrowserCapabilities`、错误码枚举 | 只返回环境事实 |
| 事件回传 | 进度、条目状态、结果码 | 由 Worker 转发，不含判定 |

**禁止导出**（出现即视为缺陷，不是"环境差异"）：

| 禁止项 | 理由 |
|---|---|
| 许可证／激活码校验、签名验证 | §13.8：桌面许可证不适用于 Web 版 |
| 授权层级（G0–G3）判定、功能位图查询的**判定函数** | 判定若在 WASM 内，浏览器内改一个返回值即可放行，等同无防护 |
| 配额扣减／退还入口（`consume`／`release` 的公开绑定） | 配额必须由服务端记账（02 §4 的 403／429） |
| 配置写入门禁（"当前层级是否允许改此配置"） | 同上，属判定而非显示 |

**允许进入 WASM 的授权数据**：仅限**只读显示数据**（如 `quota: { used, limit }`、层级标签），用于渲染；内核不得据其返回"操作失败"以外的阻断语义——该形态下内核不产生 `E4001`／`E4004` 的本地阻断，配额耗尽由服务端返回。

> **本篇结论（2026-10-28 确认）**：以编译期 feature（如 `wasm` 目标）裁掉 kernel 中基于 `LicenseService` 的阻断分支，使 WASM 产物**在二进制层面**不存在该路径，而非依赖"约定不调用"。这样不变量 #11 的验收可从"审代码"升级为"审导出面与符号表"。

## 3. `web/` 允许面与禁止面

| 允许 | 禁止 |
|---|---|
| 依内核/服务端返回结果做显示、隐藏、置灰、文案、进度 | 自行推导"当前层级能否执行"并据此放行或拦截 |
| 调用处理类接口并展示错误码对应的用户文案（方案 §4.6 分段） | 把前端判定当作唯一门禁（如"按钮可点＝有权限"） |
| 缓存并展示配额余量与到期提示 | 在前端扣减／退还配额计数，或写回本地存储当作权威值 |
| 展示"安全三件套"入口（预览、撤销、日志） | 以授权为由隐藏预览／撤销／日志（§3.1 安全能力全层级免费；§13.8 一致性约束） |

**与 §13.8 一致性约束的关系**：Web 版撤销仅限本页产物、日志仅会话内留存（§13.4、11.4-13）——这是**能力差异**，界面须显式标注，不得以"三件套"之名暗示与桌面版等价；但**不得**因层级或配额隐藏它们。

## 4. 云端通道的强制力归属

- 判定与记账在**服务端**：配额判定（QuotaBased）、白名单、资源上限均以服务端返回为准（02 §4 七端点）。
- 客户端对服务端拒绝的处置只有"展示＋引导"，不得构造"本地重试绕过"路径。
- 服务端返回的错误码沿用方案 §4.6 分段（如 403 E1006 白名单外、429 E4004 配额耗尽），客户端不做码位改写。
- **AI 助手（F15）**：同样不具强制力；AI 结果只用于建议/显示，不得据此放行/拦截；F15-lite 不在 Web/WASM 暴露授权/配额判定入口（设计 14）。

## 5. 已知可绕过路径（明确不承诺，写下来避免误判为缺陷）

| 绕过方式 | 结果 | 处置 |
|---|---|---|
| DevTools 改内存中的层级/配额显示值 | 只影响界面，服务端仍按真实配额拒绝 | 不防护；不作为安全缺陷 |
| 直接 `import` WASM 并调用处理入口 | 可处理，但拿不到配额额度（无记账通道） | 不防护；导出面本身不含判定 |
| 篡改 OPFS 中的本地配置 | 只影响本机显示偏好 | 不防护；配置不参与授权判定（03 契约） |
| 替换 `web/` 静态资源 | 自行托管即可，服务端仍旧校验 | 不防护；ADR-0002 已声明不做全量混淆 |

## 6. 验收与门禁

| 编号 | 验收点 | 判定方式 | 落点 |
|---|---|---|---|
| WB-1 | WASM 导出面无判定类符号 | 构建产物导出表逐项比对 §2 白名单 | CI 导出清单 diff（半自动）＋TW-F3 人工复核；发布前断言（ADR-0002） |
| WB-2 | `web/` 无放行/拦截逻辑 | 代码审查：授权相关只出现 `hidden`/`disabled`/文案 | TW-F3 人工 |
| WB-3 | 三件套不因层级隐藏 | 以 G0 与最高层级各跑一遍预览/撤销/日志入口 | TW-F3、TC 侧安全三件套用例 |
| WB-4 | 配额耗尽只在服务端拒绝 | 客户端伪造余量后仍收到 429 E4004 | TW-E（云契约）＋WB-1 |
