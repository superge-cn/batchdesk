>
> 产品基线 v1.15/v1.16 已确认：阶段 0 交付**中文＋英文**界面，中文默认，英文与中文同批交付同批验收。T v1.12 附录 B B8 与 TC v0.3 §4.6 已收编 I18N-01…08；U v1.2 已补英文 fallback 规则，U v1.3 沿用（§2.2.3）。

## 1. 范围

- 语言：`zh-CN`（默认）与 `en-US`；不承诺其他语言、RTL、地区变体。
- 覆盖：界面文案、按钮/菜单、错误提示、空状态、引导、设置项、授权页、Web 提示卡。
- 不覆盖：文件名/用户内容（不翻译）、日志技术字段、协议枚举值（保持英文标识符）。

## 2. 文案资源

```text
web/src/locales/
  zh-CN.json
  en-US.json
```

**现状（v0.7）**：两文件已建，各 **573 key**，key 集合逐字节一致；实际域前缀为 `app.*`（品牌/侧栏/主题）、`nav.*`、`common.*`、`task.*`（phase/state/role/progress）、`c09.*`、`feature.*`、`tasks.*`、`settings.*`、`error.*`（21 个码位 × summary/action，见 06 §3 v1.4）。运行时载体为 `web/src/i18n.tsx`（§8）。

规则：

1. **禁止硬编码用户可见字符串**；一律经资源 key。
2. key 形式：`area.component.element`（如 `rename.preview.conflict.title`）；错误码 key 固定 `error.<code>.summary/detail/action`（06 §3）。**注意**：`error.<code>.*` 这一族已按 06 §3 v1.4 建首批 **21 个码位**（summary＋action；`detail` 只进诊断日志，不建资源 key），映射表在 `web/src/errors.ts`；其余码位仍回退后端原文，见 §7 待决。
3. 两个语言文件的 key 集合必须**完全一致**；缺失/多余即构建失败。已由 `scripts/check_locales.py` 在 CI 两处（`test` job 与 `web` job）强制执行，见 §8。
4. 不在 UI 文案里拼接句子片段；使用完整句式 + 参数占位（`{count}`/`{name}`），避免英文语序问题。
5. 动态内容（文件名、路径、数量）必须转义/截断；不得把用户内容当作格式串。
6. **AI 助手文案**：`ai.consent.*`（同意/将发送字段）、`ai.status.*`（模型/配额状态）、`ai.error.*`；E6xxx 错误统一用 `error.<code>.*`（06 §3）。同意弹窗必须明确“发送什么/不发送什么”。

## 3. 格式与排版

- 日期/时间：按 locale 格式化；协议/日志仍用 RFC 3339 UTC（01 §2）。
- 数字/单位：按 locale 显示；阈值单位与数值以基线为准，不在文案里另写数值。
- 英文文案按字符长度预留空间；按钮/标签允许换行或截断，禁止因英文变长遮挡操作。
- 字体/字号/行高：中文/英文按 U v1.3（§2.2.3）；英文沿用现有 `--text-*` token，不另造字号。
- 可访问性：语言切换控件有可读标签；`lang` 属性随语言切换更新。

## 4. 语言切换与持久化

- 默认 `zh-CN`；设置页可切换；选择写入用户配置 `general.language`（03 §4.1）。
- 首次启动按系统语言？**未定**：产品基线只规定中文默认；实现前需产品确认，当前按“始终默认 zh-CN”实现。
- 切换即时生效，不重启；已打开的任务/预览不改变已生成的文案快照（避免执行中语义漂移）。
- 语言包加载失败：回退 `zh-CN` 并在诊断日志记录；不得显示空白界面。

## 5. 错误文案

- 错误码 → key 的映射由 06 统一；同一码位中英文语义一致。
- `summary` 一句人话；`detail` 技术细节（日志/可展开）；`action` 建议动作。
- 云端返回的码位不得改写（05 §4）；客户端只做本地化展示。
- 禁止把 `anyhow`/堆栈/英文内部错误直接透出（AGENTS 不变量 3）。

### 8.2 关键实现约束

1. **编译期 key 约束**：`MessageKey = keyof typeof zhCN`，`t()` 形参即该联合类型——拼错的 key 在 `tsc` 阶段报错，不必等运行期。运行期 `translate()` 再兜一层：本语言缺失 → 回退默认语言（DEV `console.warn`）→ 仍缺则返回 key 本身。
2. **插值**：`interpolate` 按 `\{(\w+)\}` 替换；缺参**保留占位符原样**（不渲染 `undefined`）。
3. **持久化**：`setLang`／`setTheme` 即时 `setState` 后写 `general.language`／`general.theme`；**写盘失败只 `console.warn` 不阻断界面**（可逆、无数据风险）。首帧用 `getConfig("general")` 回读上次选择。
4. **DOM 属性**：切换时同步 `document.documentElement.lang`（本契约 §3 的可访问性要求）与 `dataset.theme`；`system` 主题订阅 `matchMedia('(prefers-color-scheme: dark)')` 的 `change`。
5. **无 Provider 兜底**：`useI18n()` 在无 Provider 时返回默认中文翻译器，组件单挂不炸（便于单测）。

### 8.3 门禁（`scripts/check_locales.py`）

十一项：① 两文件存在且为 JSON 对象；② key 集合完全一致；③ 值非空；④ 同 key 占位符集合一致；⑤ 非默认语言不残留中日韩字符（`\u3000-\u303f`／`\u4e00-\u9fff`／`\uff00-\uffef`）；⑥ 源码引用的 key 都存在；⑦ 注释外无硬编码中文（`strip_comments` 状态机区分行/块注释、字符串、模板串，保证中文注释与用例写法不误报）。

⑧ 错误码文案族（设计 06 §3）：`web/src/errors.ts` 里每个码位必须在两语言包都有 `error.<code>.summary` 与 `.action`，语言包不得出现映射表之外的 `error.*` 码位（加了文案没接映射、或删了映射留下死文案，都会被拦下）；本项已**反向对齐设计 06 §2 的码表**——码表新增码位而映射没接、或映射里有码位不在码表，都直接红，并自带探测器自校（解析 06 码表为空即报「门禁自校失败」）。

⑨ 界面不得渲染后端错误原文（设计 06 §3：文案不得含路径/文件名/堆栈，`detail` 仅进诊断日志）：`web/src` 下非测试源码出现 `error.message`／`error.detail`（含 `error?.` 形态）即红；允许读取原文的位置只有 `web/src/errors.ts`（码表外码位的兜底）与 `web/src/lib/ipc/index.ts`（IPC 归一化层）。自校＝`ErrorBanner.tsx` 缺失时报「界面错误文案没有唯一出口」，避免出口文件改名后本项静默退化为假绿。**边界如实说明**：这是正则形态的检查，挡得住最常见的直接取用，挡不住解构（`const { message } = error`）与改属性名；本仓其余文案门禁同为正则形态，不为此引入 AST 解析依赖。

⑩ 界面不得把线协议枚举当文案渲染（§2；本项是 2026-11-04 同一处 bug 第二次出现后补的）：`web/src` 下非测试 `.tsx` 出现 `{row.status}`／`{ detail.summary.state }` 这类「整段插值就是一条成员访问」的写法即红，提示走 `labels.tsx` 的枚举→key 映射。自校＝`labels.tsx` 缺失时报「枚举→key 文案没有单一来源」。**边界如实说明**：正则只认单条成员访问，因此 `{ ...current, state: event.state }`（对象字面量、不是渲染）不误伤，代价是函数调用形态（`{labelOf(task.state)}`）与带嵌套花括号的表达式不在射程内；射程外的已知裸露点登记在 §8.5，不做「看起来全覆盖」的宣称。

⑪ 预警类别三方逐类对齐（设计 06 §2A ↔ `web/src/warnings.ts` ↔ 两语言包）：表里有类别而映射没接、映射里有而表没有、映射的 key 与表不同源、语言包缺任一语言文案或多出映射表外的 `warning.*` key，都直接红；表解析为空时报「门禁自校失败」。手法与第 ⑧ 项（错误码 ↔ 06 §2 码表）同构，对照源换成类别表。**它只保证「有没有对齐」，不保证「语义写得对不对」**——语义列是人写的概括，靠评审。

例外三类：`web/src/locales/`（语言包本身）、`web/src/lib/ipc/mock.ts`（浏览器假数据不是产品文案）、`*.test.tsx`／`*.test.ts`；单行用行尾 `// i18n-exempt`（**必须同行**，写在上一行不生效）。当前输出：`2 个语言包 × 573 个 key … 源码引用 562 个 key 全部存在，注释外无硬编码中文；错误码文案 53 个码位两段齐全，且与设计 06 §2 码表逐码对齐；界面 15 个源码文件零后端错误原文、零线协议枚举裸露；预警类别 61 类与设计 06 §2A 逐类对齐`。
