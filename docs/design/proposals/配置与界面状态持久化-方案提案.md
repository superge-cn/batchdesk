# 配置与界面状态持久化方案提案

> 状态：v1.0 已收编（方案 v1.19 / T v1.12 / 设计 03 v1.3） ｜ 日期：2026-10-28
> 决策来源：用户提出（2026-10-28）——设置配置好后，关闭应用再打开应保留上次配置；需要筛选哪些配置值得持久化。
> 已确认（2026-10-28，产品所有者）：① ConfigDocument + 独立 UiState 两层存储；② 最近目录保存（仅本机、可清除）；③ 表格列宽/排序保存，搜索/筛选不保存；④ 任务/日志/授权/AI 对话全部排除在配置之外。
> 本文件不是基线，也不改变现有冻结契约。确认后按方案 §11.6 收编，再同步设计 03/01/02/10/12/14 与 T/TC。

## 1. 结论先行

1. **普通设置已经在既有契约里有持久化归属**：设计 03 的 `ConfigDocument` 已覆盖语言、主题、默认输出位置、启动行为、处理默认值、性能、安全、日志等（方案 §6.7；设计 03 §3/§4）。本次不需要再造一套设置存储；实现按既有契约落盘即可。
2. **真正缺的是“界面/工作区状态”**：窗口位置与大小、侧栏/AI 面板/任务面板宽度与折叠、上次功能、最近目录、表格列宽/排序等，目前不在 `ConfigDocument` 中，也没有独立契约。建议新增 **UiState**（本地、机型相关、可重置、不随配置/配方导出）。
3. **任务、撤销、日志、授权、AI 会话不进入配置**：分别走 S03 任务持久化、Journal、日志存储、授权安全存储、F15 会话内历史；不得混入 `ConfigDocument`/UiState。
4. **持久化筛选标准**：只持久化“用户意图”与“不会误导下一次操作的机器上下文”；已选文件、搜索/筛选、预览计划、未保存草稿、任务进度、AI 对话等内容不持久化。
5. **保存时机**：设置类**变更即保存**（防崩溃丢失，不只靠关闭时写）；UiState 可防抖保存并在关闭时 flush；任务状态由 S03 独立负责，崩溃后提示续跑/回滚，不自动恢复写操作。

## 2. 现状与缺口

| 类别 | 现状 | 本次缺口 |
|---|---|---|
| 用户设置 | **已设计**：`ConfigDocument` 分 scope、三档优先级、版本迁移、原子写入（设计 03 §2–§6；方案 §4.5/§6.7） | 按契约实现；不需要新增字段即可覆盖现有设置 |
| 配方/模板 | C37 `recipes/`，独立 schemaVersion（设计 03 §5） | C37 增强另案（OQ-26） |
| 任务队列/进度 | S03 任务持久化；崩溃后检测未完成任务并询问续跑/回滚（方案 §7.x；S03） | 任务状态**不**归配置；只需在启动流程中接入提示 |
| 撤销/Journal | 独立映射表与 Journal（方案 §7.8；设计 01 §8） | 不归配置 |
| 日志 | 桌面独立存储；Web 会话内留存（方案 §9.6、§11.4-13） | 不归配置 |
| 窗口/布局/上次位置 | **无契约**（只有方案 §7.2“记住最近位置”、§6.10 AI 面板形态） | **新增 UiState** |
| 授权/密钥 | 授权数据独立加密（方案 §8.5；ADR-0003）；AI Provider key 亦按敏感数据处理，托管方案随 F15 实现方案单独评审 | 明确禁止进入 ConfigDocument/UiState |
| AI 会话 | F15 会话内历史，prompt/response 不落日志（设计 14 §6） | 不持久化；仅持久化面板布局 |

## 3. 持久化分类与筛选标准

| 类别 | 是否持久化 | 存放 | 判定理由 |
|---|---|---|---|
| **用户设置/偏好** | 是 | `ConfigDocument` | 改变未来操作行为；用户显式选择；可迁移、可恢复默认 |
| **机器/工作区上下文** | 是（可重置） | `UiState` | 减少重复操作，但不改变业务语义；丢失只影响体验 |
| **任务/撤销/日志** | 是（专用存储） | S03/Journal/日志 | 有独立生命周期与安全语义，不得混入配置 |
| **敏感数据** | 否（进安全存储） | OS 安全设施/会话 | 许可证、密钥、密码不落普通 JSON |
| **瞬态/可能误导** | 否 | 内存 | 已选文件、搜索/筛选、预览、草稿、滚动位置、AI 对话 |
| **文件内容/文件名清单** | 否 | — | 隐私与体积；配置/UI 状态都不保存 |

**一条反向判据**：如果“恢复它”可能让用户以为当前文件集/过滤条件/预览仍然有效，就不要持久化。能恢复的必须是**意图或布局**，不能是**上次的数据快照**。

## 4. 建议的持久化矩阵

### 4.1 用户设置（`ConfigDocument`，沿用设计 03）

| 设置 | 持久化 | 说明 |
|---|---|---|
| 语言、主题 | 是 | `general`；主题默认浅色（U v1.3 D-U5） |
| 默认输出位置 | 是 | `general`；路径属本机信息，仅本地配置 |
| 启动行为（正常/最小化） | 是 | `general`；与窗口关闭行为区分 |
| 编码策略、换行符、冲突策略、保留备份 | 是 | `processing`；安全默认值不变 |
| 并发、内存预算、大文件阈值 | 是（仅手动值） | `performance`；`auto` 为计算值，不写死 |
| 保护目录、隔离目录、保留期、占位策略、磁盘余量 | 是 | `security`；路径本机，不导出 |
| 日志保留天数、是否记录完整路径 | 是 | `logging`；隐私默认“不记录完整路径”不变 |
| 界面密度（紧凑/标准） | **待定** | U 的 B-U5 尚未定切换入口与记忆；确认后再决定放 Config 还是 UiState |
| Web 端每功能的“本地/云端”上次显式选择 | 是（本机） | 方案 §13.10.1 的“记住用户显式选择”；只恢复用户显式选择，系统默认仍为本地；放 UiState 更合适（浏览器本地、不跨设备） |
| AI 远程模型同意 | 按 F15 的 consent 口径 | 每次 `includeFileNames` 仍需逐次同意；不把“不再询问”做成默认；Provider key 不进配置 |

### 4.2 界面/工作区状态（新增 `UiState`）

| 状态 | 持久化 | 恢复行为 |
|---|---|---|
| 窗口宽高、位置、最大化、所在显示器 | 是 | 启动时校验可见区域；超出屏幕则居中/主屏，不恢复离屏坐标 |
| 侧栏宽度/折叠、AI 面板宽度/显示、任务面板展开 | 是 | 恢复布局；面板不影响业务状态 |
| 上次所在分区/功能（如“智能整理”/“重命名”） | 是 | 打开到上次功能；**不恢复文件选择、不自动预览** |
| 上次目录、最近目录列表 | 是 | 路径不存在/无权限时回退空状态；提供“清除最近位置” |
| 表格列宽 | 是（按功能） | 恢复列宽；名称列仍为弹性列 |
| 表格排序 | 是（按功能） | 恢复排序并在表头显示方向；不隐藏数据 |
| 搜索词、筛选条件 | **否** | 每次启动清空；避免“看不见文件”的误判 |
| 已选文件/勾选状态 | **否** | 文件可能已移动/删除；必须重新选择 |
| 滚动位置 | **否** | 列表内容变化后无意义 |
| 未保存的表单参数/草稿 | **否** | 用 C37 模板/配方显式保存；不恢复半成品参数 |
| 最近使用参数 | 沿用设计 03 §5 | 内存态 + `recent` 私有档；不自动回填预览；崩溃可丢 |
| C37 模板的一键/逐步骤偏好 | 是（本机） | 按 `recipeId` 存 UiState；不写入导出模板；导入模板默认逐步骤 |
| AI 面板布局 | 是 | 仅宽度/显示；**不保存对话内容** |
| AI 对话/消息/prompt/response | **否** | F15 仅当前会话；不落配置/日志 |

### 4.3 任务、撤销、日志（专用存储，不进 Config/UiState）

| 对象 | 归属 | 重启行为 |
|---|---|---|
| 任务队列、运行中/未完成任务 | S03 任务持久化 | 启动检测未完成任务，询问“续跑/回滚/放弃”；**不自动恢复写操作** |
| 任务条目进度、重试状态 | S03 | 同上；已完成项幂等跳过 |
| 撤销映射/Journal | 独立 Journal | 按保留期可用；启动不自动撤销 |
| 操作日志/诊断日志 | 日志存储 | 桌面按保留期；Web 仅会话内（不承诺跨会话） |

### 4.4 敏感数据（禁止进入 Config/UiState）

| 数据 | 归属 |
|---|---|
| 许可证、激活码、设备绑定 | 独立加密存储（方案 §8.5；ADR-0003） |
| AI Provider key/token | OS 安全存储或会话；不进普通 JSON/localStorage |
| 压缩密码、加密密钥 | 仅会话/用户输入；不持久化 |
| 文件内容、文件名清单 | 不采集、不持久化 |
| AI 对话内容 | 仅当前会话；不落配置/日志 |

## 5. 存储与 Schema

### 5.1 两个本地存储

```text
ConfigDocument（已有设计 03）
  用户显式设置；可迁移；可恢复默认；不导出
UiState（新增）
  机型/工作区状态；可重置；不导出、不跨设备、不参与配方/模板
S03 / Journal / 日志 / 授权
  各自独立存储，不合并
```

- 桌面：`ConfigDocument` 按设计 03 §3 的平台配置目录；UiState 同目录 `ui-state.json`（文件名可调整，但必须与 Config 分离）。
- Web：OPFS `config/`（已有）＋ `ui-state/`（新增）；Web 不承诺跨会话留存（方案 §13.9），UI 状态丢失只影响布局，不影响配置/任务/产物。
- **不把 UiState 塞进 ConfigDocument**：否则配置迁移、导入导出、跨形态迁移会携带窗口坐标/本机路径，污染用户配置。

### 5.2 UiState 建议字段（草案）

```ts
interface UiState {
  uiStateVersion: number;          // 与 configVersion/recipe schemaVersion 独立
  updatedAt: string;               // RFC 3339 UTC
  window?: {
    width: number; height: number;
    x?: number; y?: number;
    maximized?: boolean;
    monitorId?: string;            // 显示器变化时校验，找不到则回退主屏
  };
  layout?: {
    sidebarWidth?: number; sidebarCollapsed?: boolean;
    aiPanelWidth?: number; aiPanelOpen?: boolean;
    taskPanelOpen?: boolean;
  };
  navigation?: {
    lastSection?: string; lastFeature?: string;
    lastDirectory?: string; recentDirectories?: string[];
  };
  tables?: Record<string, {
    columnWidths?: Record<string, number>;
    sort?: { column: string; direction: "asc" | "desc" };
  }>;
  templatePrefs?: Record<string, { runMode?: "stepwise" | "one-click" }>;
  // 明确不包含：selected paths、filters、search、scroll、preview、drafts、aiMessages、taskState、license、secrets
}
```

- 版本不兼容：**重置 UiState**（恢复默认布局），不迁移、不阻断启动；`ConfigDocument` 仍按设计 03 §6 迁移。
- 写策略：防抖保存、临时文件＋原子替换；关闭时 flush；崩溃最多丢最后一次 UI 状态，不影响配置/任务。
- 单实例/多窗口：v1 建议单窗口；若未来多窗口，每个窗口独立 UiState key，禁止并发写同一文件。产品基线未定义多实例，先不新增。

## 6. 启动、关闭与崩溃流程

```text
启动：
  1. 读 ConfigDocument；缺失→默认档；损坏→保留副本并回默认（设计 03 §6）
  2. 读 UiState；缺失/版本不符→默认布局；损坏→仅重置 UI 状态
  3. 校验窗口矩形是否在任一显示器内；不在→居中/主屏
  4. 恢复上次分区/布局/列宽/排序/AI 面板
  5. 恢复上次目录；不存在/无权限→空状态并提示选择
  6. 读 S03 未完成任务；有→提示续跑/回滚/放弃；不自动执行
运行时：
  7. 设置变更→防抖写 ConfigDocument（原子替换）
  8. 窗口/布局变化→防抖写 UiState；关闭时 flush
关闭：
  9. 若有任务运行→提示（方案 §7.5）；不把“运行中”写成可自动续跑状态
 10. flush UiState；Config 已在变更时保存
```

- **关闭窗口不等于保存全部状态**：设置是变更即存；UiState 是 best-effort；任务由 S03 负责。
- 窗口关闭/最小化到托盘的行为沿用方案 §6.5/§7.5；本提案不新增托盘交互。

## 7. 隐私与安全

- 路径（上次目录/最近目录/默认输出/隔离目录）仅存本机，不上传、不写遥测；提供“清除最近位置”。
- Config/UiState 不保存文件内容、文件名清单、已选文件、AI 对话、密钥、许可证。
- 日志的“记录完整路径”仍默认关闭（`logging.logFullPaths=false`，设计 03 §4.2）；不要因持久化 UI 状态而扩大日志范围。
- “一键清理”若包含配置/UI 状态，需明确列出；仍不包含授权/试用状态（OQ-12）。
- Web：OPFS 可被浏览器回收；设置与 UI 状态均为尽力而为，不承诺跨会话/跨设备；界面按 §13.9 口径声明。
- 导入/导出：UiState 不随 Config/Recipe 导出；C37 模板运行偏好不写入导出模板。

## 8. 边界与异常

| 场景 | 处理 |
|---|---|
| 配置文件损坏 | 保留 `config.corrupt.<ts>.json`，回默认并报 E5009（设计 03 §6） |
| UiState 损坏/版本过高 | 仅重置 UI 状态，不触碰 Config/任务 |
| 显示器移除/分辨率变化 | 窗口矩形校验失败→居中主屏；面板宽度 clamp 到可用范围 |
| 上次目录被删除/无权限 | 回空状态并提示选择；不阻塞启动 |
| 崩溃/断电 | Config 已按变更保存；UiState 最多丢最后一次防抖；S03 提示续跑/回滚 |
| 关闭时有任务运行 | 提示（方案 §7.5）；不静默退出、不自动写成“可续跑” |
| Web 存储被清理 | 设置/UI 状态回默认；任务/产物按 Web 既有规则；显式提示 |
| 多实例/多窗口 | v1 建议单窗口；若未来支持，UiState 分 key、原子写；Config 冲突按三档优先级/最后写者，禁止损坏 |
| 一键清理 | 明确选择是否包含 Config/UiState；不含授权（OQ-12） |

## 9. 测试与验收建议

| 用例 | 断言 |
|---|---|
| 设置变更后重启 | 语言/主题/处理默认值/性能/安全/日志设置保持 |
| 窗口与布局重启 | 尺寸/位置/最大化/面板宽度恢复；离屏回退 |
| 上次功能/目录 | 恢复上次功能；目录不存在→空状态；不恢复选中文件 |
| 表格状态 | 列宽/排序恢复；搜索/筛选清空 |
| 强制结束/崩溃 | Config 保持最近保存值；UiState 可丢最后一次；任务提示 |
| 关闭时有任务 | 提示；不自动续跑；重启走 S03 询问 |
| 配置损坏 | 回默认 + 损坏副本；UiState 损坏只重置 UI |
| 授权/密钥/AI 会话 | 不出现在 Config/UiState；AI 对话不持久化 |
| Web | 设置/UI 状态尽力而为；清理浏览器数据后回默认；零强制力 |
| 清理/重置 | “重置界面布局”不动设置/任务；“清除最近位置”只清路径 |

**验收底线**：不选中旧文件、不恢复旧预览/草稿、不自动续跑任务、不把密钥/许可证/对话写入普通存储。
