# 12 前端与桌面壳架构

> 状态：v0.5 草案·待评审 ｜ 日期：2026-10-29 ｜ 适用：web/、src-tauri ｜ 权威：方案 §4.2/§4.4/§4.7/§13.5/§15、U v1.3、设计 01/02/03/05/06/09/10
>
> 目标结构：`web/` 只做表现与交互，`src-tauri/` 只做应用编排/适配/注入；领域规则在 `crates/kernel`。当前已建立 C09 垂直切片：`crates/platform` 共享壳层、`src-tauri/src/tasks.rs` 任务队列与 `task://*` 事件、`web/src/App.tsx` 事件驱动 React/Vite UI；真实 Tauri WebView E2E 可运行。

## 1. 分层与依赖

```text
web/ (表现层：React + TypeScript + shadcn/ui)
  │  invoke / listen（仅经生成绑定）
  ▼
src-tauri/ (应用层+壳：命令注册、任务队列、FsAdapter、授权注入、窗口/更新)
  │  函数调用（同进程）
  ▼
crates/kernel/ (领域引擎：纯变换器 + plan/apply 编排)
```

- `web/` 不得包含授权放行/拦截、文件系统规则、plan/apply 业务逻辑（不变量 11、AGENTS 前端约束）。
- `src-tauri/` 不得复制 kernel 的领域规则；只做端口实现、编排与错误映射。
- `kernel` 不依赖 Tauri/浏览器 API；WASM 构建不暴露授权/配额判定入口（05 §2）。

## 2. 前端目录（目标）

```text
web/src/
  app/                路由/壳/全局 Provider
  features/           按功能域组织（rename/csv/archive/...）
  features/ai/        AI 助手面板、流式消息、工具调用卡、同意弹窗（F15）
  features/templates/ 处理模板列表/保存/运行（C37，单步/多步）
  components/         shadcn/ui 组件与业务组合组件
  lib/ipc/            bindings.gen.ts（specta 生成）＋薄封装
  lib/events/         task:// / license:// 事件桥
  lib/state/          UiState 读取/保存/重置（窗口、布局、最近目录、列宽/排序）
  locales/            zh-CN/en-US 资源（09）
  styles/             U token → CSS 变量
  test/               Vitest/Playwright
```

- 颜色/间距/字阶只用 U v1.3 语义 token；禁止裸色值/裸像素间距（AGENTS）。
- 大列表一律虚拟滚动（方案 §6.2）；预览表/任务列表/日志列表同一约束。
- 组件不直接拼 invoke 命令名；只经 `lib/ipc` 的生成封装（ADR-0004）。

## 3. 桌面壳目录（目标）

```text
src-tauri/src/
  main.rs / lib.rs     启动、窗口、插件注册
  ipc.rs               命令注册与 DTO 映射（specta）
  queue/               任务队列、暂停/取消/重试（方案 §4.4/§7.5–7.7）
  fs/                  FsAdapter 桌面实现（方案 §4.7、04）
  license/             LicenseService 注入（永远只换实现，01 §3）
  logging/             操作/诊断日志落库与轮转（10）
  update/              更新检查（11，默认关闭）
```

- 命令名、DTO、事件与 01/02 完全一致；新增命令只改契约与 Rust，不在前端手写字符串。
- 壳层加固：capabilities 最小权限、CSP、生产构建关 devtools、不开 `withGlobalTauri`、不装用不到的插件（ADR-0002 待办②）。
- 错误映射：`KernelError` → `IpcError`（01 §3 注）；不得把内部字符串直接透出。

### 3.1 当前实现（C09 任务队列切片）

- `src-tauri/src/tasks.rs`：单 worker 串行队列；`TaskState` 按 01 §6 迁移（含 `interrupted`）；`cancelTask`/`pauseTask`/`resumeTask`/`listTasks`/`getTask`/`preflightPlan`/`recoverTask` 已注册；`applyPlan`/`undoPlan` 立即返回 `{taskId}`。
- 事件：`task://progress`、`task://state`、`task://done` 由壳层发出；`task://done.summary` 对 apply/undo 统一为 `ApplyReport` 形状。
- 取消：kernel 在条目边界检查取消令牌，已执行条目按 Journal 反向回滚并以 `journaling` 阶段上报；壳层终态为 `cancelled`。
- **任务持久化（S03）**：非终态任务快照写入应用数据目录 `tasks.json`（原子替换；损坏备份为 `tasks.corrupt.<ts>.json`）；启动加载后一律标记 `interrupted`，**不自动续跑**；`recoverTask` 提供 resume（按 Journal 已完成条目幂等跳过）/ rollback（另起 undo 任务）/ discard（保留已执行状态）。终态任务不落快照。
- **S01/S02 壳层接线**：`preflightPlan` 返回 kernel 预检报告；`applyPlan` 执行前重跑预检，磁盘空间不足返回 E2004 且零副作用；保护名单来自配置时，apply 前比较当前名单与预览快照，变化即 E1002 要求重新预览。
- 测试：`cargo test --manifest-path src-tauri/Cargo.toml --offline` 覆盖队列事件/暂停/取消状态与中断恢复三种决策；`scripts/e2e-tauri.mjs` 通过 WebDriver 驱动真实 WebView 验证 apply→undo 与执行中取消回滚。
- 未实现：`retryTask`、事件合帧节流、任务列表 UI（中断恢复提示已最小化接入 `web/`）、Playwright 浏览器矩阵。

## 4. Web 形态

- WASM 内核、解析、哈希在 Web Worker；主线程只渲染与转发事件（02 §3.2）。
- FsAdapter 由 OPFS/File System Access 实现；用户磁盘不可写（02 §3.1）。
- 能力探测结果汇总为 `BrowserCapabilities`；功能可用性由内核按能力决定，前端只显示/隐藏（02 §6、05 §3）。
- 撤销仅本页产物、日志仅会话内；界面显式声明（02 §3.4）。

## 5. 状态、事件与错误

- 任务状态以 01 §6 为准；前端不得自造 `partial-failed`/`cancelled` 语义。
- 事件只经 `task://progress`/`task://state`/`task://done`/`license://changed`；前端不轮询本地任务（云端轮询由服务端契约 07 管）。
- 任何超过一屏等待的操作必须有骨架屏/进度与取消入口（方案 §13.6）。
- 错误提示三层（摘要/详情/诊断）由 06/09 统一；前端不自造文案。
- **当前 C09 切片**：`web/src/App.tsx` 单页；`lib/ipc` 为薄封装，浏览器下用 `lib/ipc/mock.ts` 并显式标注；任务事件按 taskId 归档，避免任务在 IPC 返回前完成时丢失 `task://done`；`styles/tokens.css` 落 U v1.3 变量。未接路由/状态库、shadcn 完整组件、i18n、虚拟滚动与 Playwright。
- **AI 助手（F15-lite）**：工作区右侧可折叠面板；流式消息、工具调用卡、同意弹窗、计划跳转；**不得提供“跳过预览直接执行”**；计划预览复用现有面板，执行仍由用户确认。
- **处理模板（C37）**：侧栏入口“处理模板”；列表展示匹配建议、单步/多步、最近使用；保存入口在预览/参数页；应用只回填参数并重新预览。多步骤本机新建默认一键、导入默认逐步骤；首步预览，冲突/警告/高风险/授权失败降级逐步骤；每步仍 plan/apply。
- **界面状态（UiState）**：窗口/面板/上次功能/最近目录/列宽/排序经 getUiState/setUiState 恢复；不恢复已选文件、搜索/筛选、预览、草稿、AI 对话；任务恢复走 S03 提示，不自动续跑。

## 6. 测试

- 单元/组件：Vitest + Testing Library；IPC 用生成类型 + mock 适配（当前 C09 有 `pnpm build`、壳层任务队列单测与浏览器 mock 流，Vitest 待接）。
- 端到端：Playwright 覆盖预览→执行→撤销/日志主链、语言切换、错误提示、虚拟滚动（不要求像素级）；当前以 [`scripts/e2e-tauri.mjs`](../../scripts/e2e-tauri.mjs) 先行覆盖 WebView 的 apply→undo 与取消回滚。
- 契约：生成的 TS 绑定与 Rust DTO 的 diff 门禁（ADR-0004）；命令名/事件名不得手写。
- 无头浏览器限制：OPFS/目录授权/Worker 的真实差异用能力探测与降级用例覆盖（TW-F）。
