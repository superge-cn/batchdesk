## 1. 分层与依赖

```text
web/ (表现层：React + TypeScript + shadcn/ui)
  │  invoke / listen（仅经生成绑定）
  ▼
src-tauri/ (应用层+壳：命令注册、任务队列、FsAdapter、授权注入、窗口/更新)
  │  函数调用（同进程）
  ▼
crates/kernel/ (领域引擎：纯变换器 + plan/apply 编排)
```

- `web/` 不得包含授权放行/拦截、文件系统规则、plan/apply 业务逻辑（不变量 11、AGENTS 前端约束）。
- `src-tauri/` 不得复制 kernel 的领域规则；只做端口实现、编排与错误映射。
- `kernel` 不依赖 Tauri/浏览器 API；WASM 构建不暴露授权/配额判定入口（05 §2）。

## 3. 桌面壳目录（目标）

```text
src-tauri/src/
  main.rs / lib.rs     启动、窗口、插件注册
  ipc.rs               命令注册与 DTO 映射（specta）
  queue/               任务队列、暂停/取消/重试（方案 §4.4/§7.5–7.7）
  fs/                  FsAdapter 桌面实现（方案 §4.7、04）
  license/             LicenseService 注入（永远只换实现，01 §3）
  logging/             操作/诊断日志落库与轮转（10）
  update/              更新检查（11，默认关闭）
```

- 命令名、DTO、事件与 01/02 完全一致；新增命令只改契约与 Rust，不在前端手写字符串。
- 壳层加固：capabilities 最小权限、CSP、生产构建关 devtools、不开 `withGlobalTauri`、不装用不到的插件（ADR-0002 待办②）。**已落地（v0.19／ADR-0060）**：`app.security.csp` 与 `devCsp` 分离（生产 `script-src 'self'`、`object-src 'none'`、`base-uri 'self'`、`form-action 'none'`，唯一例外是 `style-src` 的 `'unsafe-inline'`，理由见 ADR-0060 §2）、`capabilities/default.json` 仅 `core:default` 且只作用于 `main` 窗口、`withGlobalTauri=false`、`freezePrototype=true`；上述性质由 `src-tauri/tests/security_config.rs` 的 6 项静态断言兜住（配置被改松即 CI 红）。devtools 由 Cargo feature 决定（本仓库未启），不另设配置项。
- 错误映射：`KernelError` → `IpcError`（01 §3 注）；不得把内部字符串直接透出。

### 3.1 当前实现（C09 任务队列切片）

- `src-tauri/src/tasks.rs`：单 worker 串行队列；`TaskState` 按 01 §6 迁移（含 `interrupted`）；`cancelTask`/`pauseTask`/`resumeTask`/`listTasks`/`getTask`/`preflightPlan`/`recoverTask`/`retryTask` 已注册；`applyPlan`/`undoPlan` 立即返回 `{taskId}`。
- 事件：`task://progress`、`task://state`、`task://done` 由壳层发出；`task://done.summary` 对 apply/undo 统一为 `ApplyReport` 形状。`task://progress` 按方案 §9.1 节流区间下限合帧（01 §3.2）；`task://state`/`task://done` 不合帧。
- 取消：kernel 在条目边界检查取消令牌，已执行条目按 Journal 反向回滚并以 `journaling` 阶段上报；壳层终态为 `cancelled`。
- **重试（C16 手动重试）**：`retryTask` 只对终态 `partial-failed`/`failed` 的 apply 任务生效，重试集默认为全部失败条目（`entryIds` 可选子集），生成新 taskId 引用原 planId，Journal 已 applied 条目幂等排除；web 端失败/部分失败终态出现"重试失败项"入口。
- **任务持久化（S03）**：非终态任务快照写入应用数据目录 `tasks.json`（原子替换；损坏备份为 `tasks.corrupt.<ts>.json`）；启动加载后一律标记 `interrupted`，**不自动续跑**；`recoverTask` 提供 resume（按 Journal 已完成条目幂等跳过）/ rollback（另起 undo 任务）/ discard（保留已执行状态）。终态任务不落快照。
- **S01/S02 壳层接线**：`preflightPlan` 返回 kernel 预检报告；`applyPlan` 执行前重跑预检，磁盘空间不足返回 E2004 且零副作用；保护名单来自配置时，apply 前比较当前名单与预览快照，变化即 E1002 要求重新预览。**预检门自 v0.16 起拆为可独立调用的两个纯函数**——`preflight_gate(stored, quarantine_dir, margin_floor, margin_ratio)`（跑 kernel 预检）与 `apply_gate_block(report)`（把超限结论翻成 E2004＋序列化的报告作 `detail`，retryable），`applyPlan` 只消费其结果；这样"阻断派发""零写入""环境变了判定翻转""UNC 不可达只警告"四件事都能在 `cargo test --manifest-path src-tauri/Cargo.toml` 里直接断言，不需要起 Tauri。UNC 探测根的口径见设计 04 v1.10（`unc_share_root`）。**v0.25（D4 实机缺陷修复）**：磁盘判定不再只接 `plan.kind == "c09"`——`preflight_gate` 遍历条目、按动作与 `same_volume` 把空间需求分到实际落盘的卷，`PreflightInput.disks` 逐卷交 kernel 判定；同卷改名/移动不计空间，原地重写计临时产物峰值，跨卷移动/复制/删除按源大小计入目标卷。锚点：`tasks::tests::preflight_gate_checks_disk_for_non_c09_write_plans`（不可达下限阻断、下限 0 放行），既有 c09 阻断/零写入/逐次重算断言保持；决策见 [ADR-0083](../adr/0083-实机缺陷D3D4的安全默认修复.md)。
- 测试：`cargo test --manifest-path src-tauri/Cargo.toml --offline` 覆盖队列事件/暂停/取消状态与中断恢复三种决策；`scripts/e2e-tauri.mjs` 通过 WebDriver 驱动真实 WebView 验证 apply→undo 与执行中取消回滚。
- 未实现：任务列表 UI（中断恢复提示与重试入口已最小化接入 `web/`）、Playwright 浏览器矩阵、E2E 重试场景（需可复现的失败注入）。

## 4. Web 形态

- WASM 内核、解析、哈希在 Web Worker；主线程只渲染与转发事件（02 §3.2）。
- FsAdapter 由 OPFS/File System Access 实现；用户磁盘不可写（02 §3.1）。
- 能力探测结果汇总为 `BrowserCapabilities`；功能可用性由内核按能力决定，前端只显示/隐藏（02 §6、05 §3）。
- 撤销仅本页产物、日志仅会话内；界面显式声明（02 §3.4）。

## 5. 状态、事件与错误

- 任务状态以 01 §6 为准；前端不得自造 `partial-failed`/`cancelled` 语义。
- 事件只经 `task://progress`/`task://state`/`task://done`/`license://changed`；前端不轮询本地任务（云端轮询由服务端契约 07 管）。
- 任何超过一屏等待的操作必须有骨架屏/进度与取消入口（方案 §13.6）。
- 错误提示三层（摘要/详情/诊断）由 06/09 统一；前端不自造文案。
- **危险二次确认（方案 §3.3 的 S02 行＋§7.11；U v1.3 §3.1/§3.5）**：计划含 `blocked.code == "E2009"`（保护目录命中，判定来自 kernel）时，执行入口先弹 `alertdialog`——点名被保护落点、写明这些条目**已被禁止写入、不会执行**；初始焦点落「取消」，危险按钮为 destructive 实心且不带任何自动焦点强调；确认后仍只派发非 blocked 条目。共享组件 `web/src/DangerConfirm.tsx`，C09 工作台与 23 功能页同用；后续覆盖／删除／高危规则确认复用同一载体（ADR-0048）。
- **预览失效与执行入口阻断（方案 §7.3）**：每个入口（C09 工作台与 23 功能页）保存「生成计划时的表单快照」，与当前表单不一致即关闭「执行/撤销/回滚预演」并显示状态提示，须重新预览。同一判定的**异步竞态窗口**也已关闭：`onApply` 在 `await preflightPlan` 之后按当前签名再复核一次（预检耗时期间改参数→E1002 拒绝派发，零副作用）。判定属**入口层语义**——计划是不可变产物，apply 执行的就是被预览的那份，内核无需复核参数指纹（ADR-0047）。
- **集中报告逐项点名（方案 §5.15/§5.8；ADR-0049）**：计划级 `plan.warnings` 在 C09 工作台与 23 功能页都按「类别＋建议＋风险级」列出（`.warnings`／`.warning <risk>`），不得只折成「警告 N」计数——F11 的 `parent-is-file`（清单分支的父级位置是文件）正依赖这一面把“哪几行被排除、为什么”交给用户。
- **当前 C09 切片**：`web/src/App.tsx` 单页；`lib/ipc` 为薄封装，浏览器下用 `lib/ipc/mock.ts` 并显式标注；任务事件按 taskId 归档，避免任务在 IPC 返回前完成时丢失 `task://done`；`styles/tokens.css` 落 U v1.3 变量。未接路由/状态库、shadcn 完整组件、i18n、虚拟滚动与 Playwright。
- **AI 助手（F15-lite）**：工作区右侧可折叠面板；流式消息、工具调用卡、同意弹窗、计划跳转；**不得提供“跳过预览直接执行”**；计划预览复用现有面板，执行仍由用户确认。
- **处理模板（C37，2026-11-05 落地「存取半边」）**：侧栏顶层入口「处理模板」（`templates`，TAG `TPL`，与「任务与撤销」「设置」同级，不占功能码）；列表展示名称/描述/步骤数与动作（`PlanAction` 经 `labels.tsx::actionLabel` 本地化，不印 `split` 这种枚举）、建议扩展名、更新时间；支持删除（两段式确认）、导出（v3 JSON 摊在只读文本框里可复制）、导入（低版本迁移、高版本 E1007）；**保存入口在功能页预览处**（方案 §15.2.1），存的是「这次计划的参数快照＋计划里实际出现的动作」，源路径与输出目录由壳层剔除。**不提供「一键套用」**：它要 `loadRecipe`，而模板存动作、壳层按功能码路由（一对多）——阻塞 [OQ-36](../OPEN-QUESTIONS.md)，页面用横幅写明而不是给假按钮（[ADR-0072](../adr/0072-处理模板前端只做存取半边.md)）。裁决后：应用＝回填参数＋`planOperation`＋强制重新预览；多步骤本机新建默认一键、导入默认逐步骤；首步预览，冲突/警告/高风险/授权失败降级逐步骤；每步仍 plan/apply。
- **界面状态（UiState）**：窗口/面板/上次功能/最近目录/列宽/排序经 getUiState/setUiState 恢复；不恢复已选文件、搜索/筛选、预览、草稿、AI 对话；任务恢复走 S03 提示，不自动续跑。
