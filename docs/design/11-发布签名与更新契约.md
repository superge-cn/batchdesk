# 11 发布、签名与更新契约

> 状态：v0.1 草案·待评审 ｜ 日期：2026-10-28 ｜ 适用：CI、src-tauri、发布/运维 ｜ 权威：方案 §12.5（版本/通道）、§9.7（联网边界）、§4.10（签名/审计）、ADR-0002/0007
>
> 本契约把“怎么构建、怎么签名、怎么检查更新”落成可执行流程；不定义新的产品行为或阈值。更新检查的产品口径已由方案 §11.4-9/§9.7 确认。

## 1. 版本与通道

- 单机版走 `1.x`；商业版从 `2.0` 起，不延续单机版序列（方案 §12.5）。
- 构建号区分 **B（闭门测试）/ C（公发）**；同机可并存时按通道隔离配置/日志/备份/撤销数据（README §5）。
- 每个对外构建必须有唯一构建号、提交 SHA、构建时间、SBOM 与签名；构建号不重复使用。

## 2. 构建流水线

```text
lint/deny/test（含语料生成/哈希/幂等）
  → release build（workspace release profile，ADR-0002）
  → 产物断言（符号剥离、授权关键字符串不落明文）
  → SBOM（工具待 OQ-09）
  → Windows 代码签名
  → 安装包/便携包 + checksums + 签名
  → 冒烟（T §6.2 S-A/S-B/S-C 的打包后版本）
  → 发布（B/C 通道）
```

- 手工构建产物不得对外分发（ADR-0002）；发布必须走 CI release 路径。
- 可复现构建为目标而非当前承诺；至少记录工具链、依赖锁文件与构建环境。
- SBOM 为 release artifact；`cargo-deny` 的许可证/漏洞检查在发布前必须通过。

## 3. 签名

- Windows 安装包与可执行文件使用代码签名证书；签名在 CI 的受控环境完成，私钥不进入仓库/普通开发者机器。
- 签名后校验：`signtool verify` 或等价步骤；失败即阻断发布。
- 证书/密钥轮换与吊销流程待定；旧签名在过渡期内仍可验证。
- 更新包必须验签后才能安装；验签失败不得降级为“跳过校验”。

## 4. 更新检查（产品口径已确认）

- **独立可选项**，默认手动、可彻底关闭；启用时仅拉取版本清单，不静默下载、不强制更新（方案 §9.7、§11.4-9）。
- 不采集遥测；请求只带当前版本/通道/OS 等最小字段，不带文件名/路径/用户内容。
- 更新清单与安装包均需签名；下载后校验哈希+签名，再提示用户安装。
- **防降级**：拒绝安装低于当前版本的包（除非用户显式恢复且产品确认）；实现待 OQ-06。
- 回滚：保留上一可用版本的安装包/回滚路径待定；不在本草案承诺自动回滚。

## 5. 更新清单（草案）

```ts
interface UpdateManifest {
  schemaVersion: number;
  version: string;             // 语义化版本
  channel: "B" | "C";
  minOs?: string;              // 最低 OS 版本（字符串，具体值由发布策略定）
  url: string;                 // HTTPS
  sha256: string;              // 安装包哈希
  signature: string;           // 对清单/包的签名（格式待定）
  publishedAt: string;         // RFC 3339 UTC
  releaseNotesUrl?: string;
  minVersion?: string;         // 防降级的版本下界（待 OQ-06）
}
```

- 清单本身必须签名；客户端先验签再解析字段。
- `url` 必须 HTTPS；证书校验不可关闭。
- 清单版本/通道不匹配时忽略并提示，不静默安装。

## 6. 发布检查清单

- [ ] `cargo fmt --check`、`clippy -D warnings`、`cargo deny`、`cargo test --workspace` 全过；
- [ ] 语料范围/哈希/幂等门禁通过（`check_scope.py`、`verify_corpus.py`）；
- [ ] `scripts/check_docs.py`、`fixtures/migrations/check_schema.py` 通过；
- [ ] release profile 生效、产物断言通过（ADR-0002）；
- [ ] SBOM 产出并归档（cargo-cyclonedx，CI 步骤待实现）；
- [ ] 安装包签名/校验通过；
- [ ] 打包后冒烟 S-A/S-B/S-C 通过；
- [ ] CHANGELOG 更新（用户可感知变化；内部重构记 ADR）；
- [ ] 隐私/许可证/第三方声明复核（含 OQ-01/OQ-11 状态）；
- [ ] AI Provider 配置与 API key 不入安装包/日志；模型/SDK 许可证入 SBOM（F15 启用时）。
